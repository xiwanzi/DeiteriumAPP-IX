# 管理审计只读接口

2026-09-08，本轮已授权的增量边界：提供现有 `audit_events_next` 的只读查询，权限为 `audit.read` 或 `platform.admin`。不新增封禁能力，不查询私聊正文，不扩大到与当前争议无关的聊天资料。

`GET /api/v1/admin/audit-events` 返回 v2 列表信封，data 是 `{eventId,actorId,action,resourceId,createdAt}` 数组。事件来自已存在的审计写入；空结果返回空数组，不生成示例。eventId 是数据库序号的十进制字符串，避免 JavaScript 精度丢失。

查询参数 `actorId`、`action`、`resourceId` 为精确匹配；`from`、`to` 为 RFC3339 时间，分别包含起点、不包含终点。默认查询截至本次请求的最近 30 天，每次最多 90 天，不接收未来终点。`limit` 默认 20、最大 100。超长、重复、未知参数或非法时间返回 400。

结果按 createdAt、数据库序号倒序；`page.nextCursor` 冻结操作者账号作用域、过滤器、时间段和初次查询时最大事件序号。后续请求可以仅传 cursor；若再次提供过滤器，必须保持相同。新写入事件不会混入旧查询，另一管理员的游标不能复用。每次请求重新校验权限；游标不是授权凭据。时间索引由独立迁移 `017_admin_audit.sql` 添加，不修改已部署迁移。

网页管理区按真实权限显示审计入口，支持精确筛选、日期范围、刷新和加载更多。此接口只暴露审计表已有事实，不声称覆盖尚未写入该表的所有动作。
