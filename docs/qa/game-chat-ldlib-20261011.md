# 游戏聊天本机验收

2026-10-11，工作区 `game-chat-ldlib`。这是本机候选与隔离环境证据，尚未部署生产服，也未操作生产账号/订单/媒体对象。

## 最终视觉依据

以 Web V12 最终级联样式为基准；用户后续要求覆盖其中的演示数据与工具图标尺寸：单色粉色 ID → 固定「封弊者」→ 位置/频道，三个工具按钮统一 36px 点击区域、24px 可见轮廓。此前以旧截图给出的“91分”已撤销，不作为本轮验收结论。

完整页使用物理像素尺寸，HUD 保留 GUI × 0.6。完整页包含原点阵、14px 模糊及分段颜色/透明度渐变；弹窗另有 22px 背景模糊。圆点与圆角采用正确透明度混合的子像素覆盖着色器；原素材的颜色遮罩单独处理，避免灰色箭头仍被黄色源图染色。

字体使用 Harmony、Gilroy、Novecento 和 Geist/品牌 IX。纯表情为 29px 无气泡，混排中的彩色表情走原生 RGBA 字形，正文继续使用 SDF；避免 LDLib2 将彩色 bitmap 转成单色轮廓。输入框工具插入保留光标和选区。

[独立复核](game-chat-web-review.md)的末节记录本轮问题闭环；早期节次保留为历史差异。已对照完整页、发送禁用/悬停、内置贴纸、个人库、常用/冒险表情、私聊列表/会话/批量固定、分享预览、图片查看器、快捷聊天与世界 HUD。音效使用 Web 六组素材及对应音量；关闭、返回、删除、静音不混入原版按钮声或错误的发送/打开音效。

## 游戏与渲染

- NeoForge 1.21.1，LDLib2 2.2.39，Java 21，Windows x64，RX 9070。
- 1440×900 / GUI 3：最终 UI 场景 105 步、4 项断言通过。断言覆盖动态媒体首帧、查看器返回个人库、选区表情替换和批量取消固定。
- GUI 2 与 1920×1080 / GUI 4 均完成 105 步、4 项断言的完整交互场景；各次报告与截图分别保存在 `output/qa-game-chat/web-parity-gui*`。报告中的时间和步数对应当次源码，后续小修不冒充此前已经验证。
- GUI 3 的 254 帧样本：P50 8.36ms，P95 9.54ms，最大 10.00ms。这是上述显卡、隔离世界与测试消息的样本，不代表所有玩家电脑或超长在线会话的保证。
- 同背景 Web/游戏对照：左墙、门框边缘、草地中段的 RGB 平均绝对差分别约 0.364、0.452、0.402 / 255。右侧天空在两次游戏截图之间亮度变化，不把该区域误差归因于模糊。独立报告与原图见本文件旁的 `game-chat-web-background-review.md`。

## 媒体、身份与路由

- 客户端单元测试 4 项通过；Core 测试 35 项通过。
- 本轮已执行 Go 全包测试与游戏聊天会话/私聊附近附件集成测试；隔离 MariaDB 使用 33319 端口。
- 真实 NeoForge 客户端 → 本机 Core → 隔离 Go → 模拟 S3 的上传、读取与消息回流完成：2 次 PUT、2 个对象、2 条公屏消息；有 App API 格式的读回记录。这不是生产 S3 或真实已安装 App 的线上收发验收。
- 附近边界：50 米接收，51 米不接收，不同世界不接收。
- 团队使用现有 DeuteriumTeams / FTB Teams 集成；跨服成员接收，非成员不接收，成员移除后的下一条消息不再接收。
- 凭据限定聊天用途，游戏不持有节点/管理密钥；附近、团队、私聊附件的授权在服务端校验，不靠客户端隐藏。
- App 转发正文使用结构化来源信息，不再拼接重复的 ID/服务器/App 前缀。

原始证据位于 `output/game-harness`、`output/game-team-harness`、客户端 `build/ldlib2-uitest`。本次未重跑 App 安装验收，也未更换生产插件或服务。

## 交付与范围

客户端与配套 Core/Go 分开打包。客户端使用 Windows x64 图片编解码组件；其他操作系统的 native 构建未列入本次验证。客户端运行 JAR 排除 UI/网络场景、隔离媒体服务器及测试资源。

候选不携带生产配置、数据库或密钥。后续正式接入需要配套服务上线，不能只把客户端 JAR 安装成功说成线上图片、私聊和贴纸已接通。
