# 黑色渐变、Logo 与分享功能修正

2026-10-12 用户确认：中性黑色背景渐变，提高 Logo 清晰度；移除持续实时位置，将地点信标改为一次发送的“当前位置”，用旧实时位置图标；新增当前主手物品分享，消除重复原始行与翻译键。后续确认当前物品**先仅支持世界频道**。

- 背景使用中性黑灰，平滑曲线过渡，并在左侧和中段降低场景颜色影响；浮层改中性深灰。
- Logo 保持原 Geist / IX 字体，取消非等比横向拉伸，提高字形采样并对齐像素。位置图标为 32px；物品图标使用 Minecraft 原生主手物品预览，空手为通用箱子图标。
- “当前位置”只提交 live=false 的现有服务器确认位置请求。新客户端不再提供持续共享入口；旧服务端为旧客户端保留的兼容代码未更换，旧共享在离线或既有超时后终止。
- 世界频道物品按钮发出 TrChat 已启用的 `[item]`，物品由服务器读取，保留原权限和 30 秒冷却；空手本地提示，其他频道不发送、不转向世界频道。
- TrChat plain serializer 会留下 `[block.minecraft... x1]`；客户端按当前语言归一化物品翻译键后匹配原始富文本。覆盖原始包先到、桥接包先到、原始行已显示三种时序，保留一条气泡及原悬停/点击信息。异步富文本补齐时刷新对应行布局，保留顺序。
- 正式 TrChat 2.4.9 的 Amiya 配置已只读确认 `[item]` 开启、权限 none、冷却 30s。未修改 TrChat 或 Core，也未向生产聊天发送测试消息。

客户端构建与单元测试通过。实际 NeoForge + Modern UI + IMBlocker + Xaero、中文语言下联合运行 `41348_7222e168`：两个场景均 PASS，共 136 步、11 项检查。含三种物品消息到达时序、悬停信息保留、单次位置预览和私密频道拒绝分享；同时完整聊天交互回归通过。截图显示中文物品名称且没有重复原始行。UI 场景与夹具不进入正式 JAR。
