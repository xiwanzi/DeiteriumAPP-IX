## 第二轮：纹理与整体比例

用户在首轮 `4060222` 基础上要求加入纹理壁纸并继续优化其余视觉，明确表情除外。本轮只调整聊天样式并新增原创 SVG 线描壁纸，保留表情资源、分类、菜单布局和动画。

- 壁纸包含方块、镐、房屋、纸飞机、植物、星月等线描，使用同一份本地 SVG 重复铺设。浅色透明度 .16、深色 .24，配合不同底色和线条色阶；纹理层不接收指针事件，不会阻挡消息操作。
- 会话列改为 320–380px，1440px 视口下为 360px。消息列、头栏、输入栏共享 720px 宽度基准；较窄窗口保持可用空间，手机继续单列切换。
- 公共与私聊的头栏统一为 50px 悬浮层，单行输入栏同步减薄为 50px。背景、头栏/输入栏、消息气泡分别使用明确色阶，输入栏周围保留壁纸，不再用大块底色遮住纹理。
- 消息正文提升为 16px、昵称 13px、时间 11px；组末头像为 36px。列表略收紧行高，保留可读的 14px 摘要与 12px 时间。仍无蓝色输入聚焦线。
- 原 259 个 SVG 表情、表情组件和菜单 CSS 主体均与 `4060222` 一致，没有替换画风或重新调整菜单。

本轮生产构建、39 项既有浏览器回归、7 项新增壁纸/比例检查通过。检查浅深色 1440px、1840px 和手机宽度画面，确认窄屏无横向溢出，壁纸不拦截操作，头栏和输入栏宽度一致。因未改业务逻辑，没有重复运行首轮的业务单元测试。

## 已确认方向

用户要求逐步优化现有 Web 聊天：侧栏、会话列表和整体布局参考副屏上已登录的 WhatsApp Web；输入区、群聊和圆润的细节参考 TG Web。聊天输入框不能出现蓝色聚焦线，表情菜单需要展开/收起动画和高清图标。

通过系统无障碍与屏幕查看实际参考页面。仅在用户指定的 WhatsApp 自用会话发送了 1 条短文本测试；TG 群聊只查看设计并展开/收起表情菜单，没有输入或发送消息。参考截图留在本机忽略目录，不纳入仓库。

## 实现

- 保留商城、市场、委托、信息、钱包、我的及已有管理入口。桌面聊天使用 64px 窄侧栏，主题、通知、购物袋进入侧栏底部，移除聊天页重复顶部工具栏；会话详情默认收起，仍可主动打开。
- 会话列随窗口宽度调整，增加全部/未读/私聊筛选、搜索清除及空态。显示真实会话时间、未读数和按会话保存的草稿，不新增收藏或其他服务端能力。
- 公共聊天采用居中的消息列与悬浮圆角头部、输入区。同一玩家、同一来源、同一日期且相隔不足 5 分钟的连续消息紧凑排列，昵称在组首、头像在组末；时间与服务端接受状态进入气泡。没有增加已送达/已读回执。
- 输入区和搜索框无蓝色聚焦线。附件在输入区左侧，表情和发送在右侧；鼠标点击发送时保持输入焦点。现有公共单段消息、私聊换行及长度限制继续生效。
- 公共、私聊和 AI 使用同一套表情选择界面；只有已有公共媒体能力提供贴纸入口。菜单在输入框上方作为浮层展开，以 240ms 位移/缩放和 160ms 透明度过渡，不抬升输入栏；支持点空白、Escape 和切回键盘关闭，尊重减少动态效果偏好。
- 分类和操作按钮使用 SVG；菜单中的 259 个表情采用本地 [Twemoji v17.0.3 SVG](https://github.com/jdecked/twemoji/tree/v17.0.3/assets/svg)，总计 359,878 字节，不依赖外部 CDN 或新增 JS 运行库。原图未修改，CC BY 4.0 许可及来源随构件保留，关于页可查看图形来源和许可。

没有修改身份、资金、聊天传输协议或数据库。Web 仍按原有服务能力发送消息与媒体；本轮不扩展私聊贴纸、任意新群组、语音或视频通话。
