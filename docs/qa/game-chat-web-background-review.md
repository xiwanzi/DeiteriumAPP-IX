本次不评分。结论：**所复制这一版游戏磨砂接近Web的14px，未发现“明显模糊不足”的证据。** 以同背景实验替代先前不同世界画面的主观判断。

## 固定证据

- 原图复制为 output/qa-game-chat/web-background/review-same-background.png；游戏完整页复制为 output/qa-game-chat/web-background/review-game-shader.png，避免后续运行覆盖。
- 实際两图1920×1080，非1440×900；浏览器也使用1920×1080、DPR1。
- Web通过浏览器临时style将.world换为原图，100%×100%显示；只隐藏#app，保留原版blur/shade/grain。未修改dist源码。
- 等待400ms稳定后输出 output/qa-game-chat/web-background/review-web-same-background.png。
- 原图包含左侧HUD，比较区域刻意避开该HUD及游戏完整页控件。不比较左侧文字区域。

## 像素对比

RGB每通道0–255，MAE为区域所有RGB通道绝对差均值。

| 区域（物理像素） | 游戏均值RGB | Web均值RGB | MAE |

| 左墙(500,360)-(660,480) | 24.28,29.52,31.62 | 24.24,29.48,31.60 | .364 |
| 门框边缘(650,330)-(820,550) | 36.41,44.16,50.46 | 36.50,44.27,50.62 | .452 |
| 中段墙(1030,270)-(1120,330) | 50.05,53.38,55.36 | 49.70,53.07,55.01 | .620 |
| 中段草地(800,700)-(1000,850) | 34.30,44.84,32.46 | 34.14,44.63,32.29 | .402 |

上述差异小于1/255平均通道值，但不声称整个画面逐像素相同。

## 边缘扩散的受控半径实验

只改变Web blur半径，其他mask/shade/grain/背景保持原样，分别输出 review-blur-8/10/12/14/16/18/20.png。比较门框边缘 (680,360)-(780,500)：

| Web blur | 对游戏MAE |
| ---: | ---: |
| 8px | 1.0305 |
| 10px | .7656 |
| 12px | .5321 |
| **14px** | **.4419（最低）** |
| 16px | .4972 |
| 18px | .7102 |
| 20px | .9117 |

高对比边缘对半径最敏感，最低值位于原版14px，支持当前扩散强度匹配目标，而非应继续盲目加blur。平墙/草地低纹理或遮罩较重，区分半径能力较弱，不用它们单独估计半径。

## 捕获限制

右侧无mask天空(1750,100)-(1880,400) MAE12.933，显著高于其他区域；那里Web无模糊/遮罩，差异不能归因于blur。游戏原图与full图并非同一帧，天空/光照在两次截图间有变化。不要把该区域纳入shader颜色误差判断；若追求更小数值，需要冻结昼夜/天气并在同帧渲染前后捕获。
