# 人工回复邮件页脚

2026-10-04。本机实现，尚未推送或部署。自动收件回执保持此前确认的版本。

## 结构与适用范围

- 邮件从客服填写的正文开始，保留段落、换行与编号文字；正文不会自动改写，HTML 输入会安全转义。
- 正文之后附客服署名与「Deuterium IX 玩家支持」。工单回复使用写入该条回复时保存的署名，后续改昵称不会改变这封待发邮件的署名。
- 页脚沿用验证码邮件的徽章与字标，但缩为 36px 徽章、16px 字标，并以细分隔线与正文分开。工单编号、帮助中心、实际回复邮箱和版权采用小字。
- 明确提示「您可以直接回复本邮件继续沟通」，没有验证码邮件的禁止回复文案、验证码标题、状态块或通知式大标题。
- 适用于企业邮箱发送的工单人工回复，以及后台「写邮件」中的企业邮箱邮件。独立写信没有工单编号时不显示该行；DM 通知、内部 Help 转交与自动回执不套用此页脚。
- 工单消息与队列继续单独保存客服正文，发送时附加签名与页脚。无需数据库迁移，不重复将页脚写入工单记录。

## 验证

- `go test ./internal/notify ./internal/httpapi ./internal/store` 与对应包 `go vet` 通过。
- 两项隔离数据库集成测试（`-race`）通过，10.332 秒：人工回复生成 HTML / 纯文本 / CID 徽章、线程引用与回复地址保持、署名快照保持、内部备注不外发、普通企业邮箱写信带页脚且不伪造工单、DM 原内容不受影响。
- 模板验证正文与姓名转义、非法回复地址拒绝、原始主题保留、可回复提示和纯文本备用内容。
- 浏览器查看桌面与手机预览；320 / 390 / 600 / 760px 无横向溢出，320px 连续长内容能换行，徽章加载成功。另生成深色偏好预览；不等同于真实邮件客户端投递验证。
- 与提交前比较，自动回执源码和 HTML 模板完全未改。未发送真实邮件、修改线上配置或重建 App / Web。
