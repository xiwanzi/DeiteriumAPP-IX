# 公共聊天媒体本机候选验收

后续发布：2026-10-09 19:21 已上线 App 2.0.22 / Web 2.0.31，真实 OSS 与公网验证见[上线记录](../deployment/deuterium-2.0.22-live.md)。下文是发布前的本机验收快照。

2026-10-09。基线 `3960c5a`，维护分支 `xiwanzi/chat-media`，工作区 `.worktrees/chat-media`。本轮没有推送、合并、部署，没有登录真实账号或写入线上公屏/OSS。

## 已实现

- 公共聊天 Emoji、单图选择/预览、客户端压缩、GIF 与静态/动态贴纸；没有批量、原图或画质选项。
- 云端个人贴纸最多 10 个；满额须手动删除，不自动替换。按压缩主图 SHA-256 复用，缩略图变化不会复制主图。
- 普通媒体及未发送上传三天；消息期限各自计算；永久收藏阻止物理回收，最后引用释放才清理。数据库文字保留，玩家补拉最近 30 天。
- App 独立 500MiB 聊天缓存，无时间过期、旧媒体优先淘汰；两种清理方式、待发送隔离、本机已缓存图片不受服务端到期影响。
- 本地预览、后台队列、原发送结果恢复；不展示存储服务术语或上传百分比。查看器展开/关闭、双击、双指缩放、长图阅读；动图可见时播放，减少动效时停止自动播放。
- 游戏仍走旧文字投递，图片和贴纸降级为 `[图片]` / `[贴纸]`；没有更换插件。

### 浏览器

在本机 Vite、真实 Chrome、真实 Worker/WASM 中操作现有 Messenger 组件。接口及对象传输使用隔离夹具，不连接真实账户。

13 项检查通过：单个文件入口、无批量属性、Emoji 光标插入、相同图再次发送无 PUT、双击缩放、两指缩放、关闭后聊天位置不变、导入不直接发送、贴纸发送不重复上传、满 10 禁止添加、删除释放名额、390px 宽度无横向溢出、无页面运行异常。截图同时检查浅色消息、深色贴纸面板和窄屏。

### Android 原生

使用独立包 `com.deuterium.app.uilab.chatmediaqa` 和独立测试 APK；默认服务地址为不可用的本机地址，仅测试 APK 注入回环接口与内存对象传输。没有覆盖原 App。

- 实际压缩 1080×6500 中文长截图；保留宽度和文字内容。GIF 输出 12 帧、960ms，逐帧可以解码。
- 过期云端媒体已有本机文件时，不发服务端读取请求。
- 用 500MiB 测试文件验证先淘汰最旧媒体，总占用不超限。
- 仅清媒体保留记录；清记录及媒体清除本机记录；待发送文件两种情况下都保留。
- 模拟消息已经提交但响应丢失，原请求恢复后不重复 POST；再次发送同图不增加 PUT。
- 浅色动图实际像素随时间变化；深色、减少动效时保持静止。
- 公屏图片、贴纸满额网格、全屏查看、双击缩放与关闭通过。
- 键盘与表情栏切换保持输入框位置，草稿与引用继续由原状态保存。

## 复现入口与交付状态

- Android：`gradlew.bat :ui-lab:testDebugUnitTest :ui-lab:lintPerformance :ui-lab:assemblePerformance`。
- 独立原生夹具：构建 `assembleChatMediaQa`、`assembleChatMediaQaAndroidTest`，使用 `-PdeuteriumTestBuildType=chatMediaQa`；Instrumentation 参数 `chatMedia=true`、`theme=1/2`。
- Web：`npm test`、`npm run build`。本机浏览器夹具和截图位于 `web-app/output/playwright/chat-media/`，原生截图位于 `output/playwright/chat-media/`。
- Go：回环隔离数据库下 `go test -race -tags integration ./...`；HTTP 全套需 `-timeout 30m`。聊天专项为 `-run TestChatMedia`。测试创建随机临时库，不使用生产 DSN。
- 跨端编码样本：设置 `DEUTERIUM_CHAT_MEDIA_FIXTURES` 后运行 `go test ./internal/objectstorage -run Chat -v`。
- 本机构建目录：Android `ui-lab/build/outputs/apk/`、Web `web-app/dist/`、Go `output/chat-media-candidate/deuterium`。

普通 App 构建仍是 2.0.21 / 22100，Web 仍为 2.0.30，均为未发布代码候选，不作为线上更新交付。正式发布需递增版本并先部署 Go/数据库迁移。真机上的双指手感、低端设备耗时、真实弱网和线上 S3 联调尚未验证；不能将模拟器或内存对象传输的结果称为线上验收。
