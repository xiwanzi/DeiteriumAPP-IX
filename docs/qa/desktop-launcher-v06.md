# 启动器社区与程序发布验证

本轮 Web 2.0.19 / 配套 Go 从主线 `c9e4c52` 开发。Windows 程序在独立启动器仓库构建为 0.6.1。

## 本机检查

- Web 68 项测试通过，Vite 生产构建通过。
- Go 全部普通包测试通过；桌面启动器相关集成测试通过，并通过竞态检测。
- 新签名验证覆盖错误签名、内容篡改、平台/版本不匹配、无效地址、异常大小及不唯一字段。
- 隔离数据库验证发布权限、乐观修订、递增版本、幂等重复请求和唯一审计记录。
- 实际 0.6.1 签名更新包通过完整发布处理器测试：不完整对象返回冲突且保持未发布状态，完整对象经过大小/SHA-256 验证后发布，重复请求保持同一修订。测试只使用本机随机数据库与回环 S3 测试服务。
- 独立浏览器检查了内嵌登录布局和管理端“启动器版本”页。浏览器用例未操作生产账号或发送业务消息。

浏览器使用的常驻隔离测试环境在检查后到达自身超时并退出；这是测试环境的生命周期限制，不作为产品测试失败或通过计数。独立浏览器及本机网页预览进程已关闭。

Windows 端另验证了提示坐标、图标多尺寸、真实社区加载、切换保留输入、不同缩放下最小化恢复、不可跳过的更新提示、安装中断恢复和独立更新器预览不写入客户端。
