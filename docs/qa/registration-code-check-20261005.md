# 获取验证码时校验与倒计时验收

2026-10-05，分支 `xiwanzi/registration-code-check`，工作区 `.worktrees/registration-profile-check`。本节为本机候选记录，发布状态以后续上线记录为准。

## 行为

官网、Help、社区和 App 点击获取注册验证码后立即进入倒计时；后台校验正版 ID，通过才排队验证码邮件。查询期间保留输入能力，失败显示错误并恢复获取按钮。修改 ID、邮箱或关闭/切换页面会使旧请求的 UI 结果失效，不覆盖新输入。仅缓存成功的 ID 查询 10 分钟，同一 ID 换邮箱不重复查询。

成功结果绑定服务端验证码记录，最后注册不再查询。迁移前的旧验证码在最终提交时仍校验一次。验证码依旧单次消费、到期失效、五次错误封锁；独立游戏身份验证、UUID 绑定、白名单与旧账号保持。
