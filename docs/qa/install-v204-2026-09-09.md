# 2.0.4 安装退出与启动回归

2026-09-09。用户明确授权在 2.0.4 上补修安装后的退出/加载问题，然后发布并推送源码。最终 APK 为 **2.0.4（20401）**，20400 保留为此前候选，20402 仅用于本机安装流程夹具，不公开发布。

## 修复

- 在完整性、版本和签名校验通过且系统安装器成功打开后，关闭本应用旧任务；保留已验证 APK 和授予安装器的 URI 读取权限，不强杀进程、不注销账号。
- 新增仅接收系统 `MY_PACKAGE_REPLACED` 的非导出接收器，处理从旧 App 发起的覆盖安装，清理残留旧任务。若用户已打开新版界面，迟到的包替换通知不会关闭新界面。
- 主窗口获得焦点时也确认启动动画已交接，避免热启动或安装返回时缺少原生 SplashScreen 退出回调而永久停在加载层。
- 取消安装保留现有版本，重新打开可以正常进入；原签名、资金请求恢复和账号数据保留。

## 本机证据

Android 121 项单测通过，Debug APK 与独立 QA APK 构建、Lint 通过。模拟器使用真实系统安装器完成 20401 → 隔离夹具 20402：旧 App 任务退出、安装确认页保留、安装器可读已验证 APK、点击 Update 完成安装，随后 Open 和桌面再启动均进入正常界面。取消安装另行验证，版本保持 20401且可以正常重开。

另外使用原 2.0.3（20300）APK 创建旧任务，经 ADB 覆盖安装最终 20401，系统包替换广播自动移除旧的可见任务，新版再次打开正常。仅检查真实最近任务列表，排除 Android 内部暂留的隐藏任务对象。读取 UI 层次时等待窗口完成切换，并按 UTF-8 解码；没有把测试工具在窗口切换或编码阶段的失败计为产品失败或通过。
