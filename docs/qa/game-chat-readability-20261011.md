# 聊天可读性、客户端默认项验收

2026-10-11 用户要求：团队图标清晰，消息略微放大，文字在气泡中正确对齐；低像素窗口减少同屏信息以保证可读。后续明确要求彻底禁用原版背景音乐（保留自定义音乐、唱片及其他音效），本次重新绑定 T，并将小地图移至右上。

## 实现

- 团队图标原图 123×70 被缩进 24×24，现保留比例，显示约 38×22；导航其他图标 28px，标签 14px，使用 alpha 蒙版纯色。
- 消息正文目标 18px，名字 16px、次要信息 13px；文本原点对齐物理像素。正文行距 26px，气泡横向留白完整界面 12px / HUD 10px、上下各 6px，并按行盒居中。
- 宽度 <1440 或高度 <820 时启用紧凑信息模式：不缩小正文，聊天列适度加宽、隐藏称号等次要信息；HUD 最多 6 条（常规 10 条），实际数量受消息高度约束。依据窗口像素，而非无法可靠获取的显示器英寸数。
- HUD 字体/头像尺寸按物理像素计算，避免 GUI 2/3/4 改变字体大小和头部拥挤。次要信息逐段检查宽度，放不下不绘制；阴影帮助亮背景下辨认名字。
- `keybindings-v3` 再确认 T 快捷聊天、Alt+T 轮盘、TAC 配置入口未绑定；Enter 完整页面保持。
- 首次进入世界通过 Xaero 已加载的 ModuleTransform 设 fromRight=true、fromBottom=false、centered=false、x/y=0，再调用它自身的保存方法；一次标记后保留后续手动设置，不修改地图或路标文件。
- DeuteriumBGM 原逻辑在开场避让、无曲目或失败等条件下解除原版抑制；用户本轮选择彻底禁用后，在 PlaySoundEvent 最低优先级拦截 `minecraft:music.*` 且分类为 MUSIC 的实例。自定义 BGM、唱片、聊天音效不匹配该条件，不修改音量滑块，也不修改原音乐模组源码或音频。
