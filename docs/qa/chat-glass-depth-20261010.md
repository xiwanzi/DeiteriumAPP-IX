# 聊天玻璃通透与面板圆角修正

2026-10-10，基线 App 2.0.23 / Web 2.0.32，工作区 `.worktrees/chat-media`，分支 `xiwanzi/chat-glass-depth`。

用户明确要求：输入栏更通透，表情面板因信息密度更高而使用更强模糊与更厚底色；浅深色效果分别调整，整个下方面板只在顶部两个角圆角，底部直铺到屏幕底边。沿用此前“直接推更新”的要求，本轮完成验收后发布。

## 修正

- 原输入栏取样的是页面氛围底色，表情面板接近实色，且消息列表停在输入栏上方。现在消息区延伸到输入栏/面板后方，最新消息仍通过底部留白保持在输入栏上方，滚动历史时可看到内容从玻璃后经过。
- Android 先测量输入区，再以同一高度布置消息留白，避免逐帧回写尺寸造成一帧错位。独立记录“页面底色 + 实际消息”的合成层，玻璃自身不进入该取样层，避免循环绘制；不做截图回读。
- 取样底图包含不透明页面底色，再执行模糊，解决透明边缘让原始细文字从下方漏出的问题。只有颜色和低频轮廓透出，控件与文字保持清晰。
- 输入栏和密集面板分别沿用用户材质设置的比例：默认模糊约 14dp / 45dp，面板更厚；浅色采用亮色薄底，深色采用略带冷色的暗底。保留玻璃开关及材质控制，关闭后两者回到实色。
- 表情/贴纸面板只保留顶部两个 28dp 圆角，左右贴边、底部方角直铺至屏幕底边，玻璃背景覆盖手势导航区，按钮在内部避让系统手势。没有四周悬浮留白；内部内容裁切在轮廓内，底部切换条继续保留自身圆角。既有贴纸圆角、透明背景和 GIF 播放不变。
- Web 同步改为叠放输入区、真实消息背景模糊和面板顶部圆角/贴底布局；默认输入栏 14px、面板 45px 模糊。浏览器不支持背景模糊或要求减少透明时回退实色。Android 31 以下使用更密实的兼容材质。

## 验收

- Android 172 项 JVM、QA/performance 构建、R8/资源压缩与 lint 通过。
- 原生浅色、深色/减少动效、关闭玻璃三组验证通过。使用实际聊天消息里的双色细纹图片滚动到输入栏和面板后方，确认取样位置、背景透出、模糊层次及整体圆角。关闭玻璃时同一位置回到实色。
- 键盘/表情互换、输入栏连续位移、组合 Emoji 删除、贴纸限额、GIF 与圆角像素、预览抽屉手势、图片查看器、缓存及未知发送恢复均通过。
- Web 81 项单元、生产构建通过；13 项媒体交互回归、19 项输入/动效/布局检查通过。
- Web 材质专项确认实际消息位于玻璃后方、输入栏/面板独立模糊与遮罩、顶部圆角和方形底角、浅深色。截图像素比较：输入栏双色差约 80.9，面板约 28.6（浅色）/32.7（深色），说明面板更强地压低背景对比，同时仍保留颜色；圆角外像素与原背景一致。

截图与像素记录在 `C:/DeuteriumAPP/output/chat-glass-depth/`。原生日志 `.tools/chat-glass-native-light.log`、`chat-glass-native-dark.log`、`chat-glass-native-off.log`；Web `.tools/chat-glass-web-{motion,regression,material}.log`。

验收仅使用隔离 QA 包及本机浏览器替身，没有向生产频道发送样本。后端、数据库和游戏插件不改，本轮不重跑 Go/资金测试。真机手感仍以设备实测为准。
