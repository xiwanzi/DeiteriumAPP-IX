## 行为

- HUD / T 快捷聊天显示 `玩家名 [当前铭牌] [服务器] 时间`；复用 Core 的 `player-title` 投影，铭牌逐字颜色、重命名与佩戴变更同步。保留头像、正文和气泡样式，不复制 LP 前缀或新增服务端状态。
- 解除原先仅完整聊天且非紧凑布局才允许显示铭牌的限制。继续检查实际文字宽度防止覆盖后方内容；极长名字或铭牌在宽度不足时仍可能隐藏头部次要字段，此轮未新增换行布局。
- HUD / T 只使用本次连接实时消息集合；加载的历史和会话最后一条摘要不会因打开 T 而重新显示。完整私聊页保留历史；发送失败重试等业务查找仍读取完整集合。
- MMO 铭牌页在 mouseDown 入口按当前屏幕坐标重新命中，使用 LDLib2 的变换反算 API，不再依赖上次绘制缓存的悬停对象。关闭过程中仍拒绝点击；协议、权限、佩戴确认不变。

## 依据与验收

用户录像中的卡片预览是本地状态切换，不等待服务器。当前 LDLib2 2.2.39 的 Widget 点击直接使用 `lastHoveredElement`，移动事件也不立即重算目标；铭牌页此前没有补充刷新。新增测试在两卡片之间移动后不推进绘制帧，先复现旧 Widget 错选旧卡片，再验证生产 Screen 的点击路由选中新卡片及反向切换。

旧私聊问题源于 `ChatStore.hud()` 返回全部记录，而 `ChatTimeline` 打开 T 时将透明度统一置为 255；仅依赖 `receivedAt=0` 使历史淡出无法隔离快捷聊天。回归覆盖历史摘要、后加载历史页、新私聊、重复历史及断线清空，确认历史仅保留在完整会话。
