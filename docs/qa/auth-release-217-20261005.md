# 登录注册修复 2.0.17 发布验收

2026-10-05，用户授权合并与上线 App、社区、官网、客服中心及配套 Go。App 2.0.17（21700），社区 Web 2.0.27。此记录为发布前验收，真实上线状态以部署记录为准。

## 完成内容

- 发码查询失败与邮件入队配额分开；限流返回真实剩余秒数，客户端维持冷却；未知发送结果不立即开放重发。
- App 找回/修改密码弹窗的冷却期限保存在当前 API 实例中，关闭重开不丢失；不保存验证码和密码。登录提交固定账号和模式，旧响应不错误锁定新的输入账号。
- App、社区、官网和客服中心统一验证码名称与发码文案，删除排队提示及重复解释；App 精简后的间距和社区标题下方间距已调整。
- 明确的阿里云 DM 无效地址冻结 24 小时，所有验证码用途共用；不影响正常登录。SMTP 全局/个人无效地址库拒绝可直接生效，异步投递事件接口已实现但云端规则未配置。
- 用游戏 ID 找回已绑定邮箱的账号不重复扣额度，冷却/冻结拒绝不消耗发码额度。

## 发布边界

服务器预检仍为 App 2.0.16 / Web 2.0.26：50 个账号、27 笔订单、5 个委托、12 个工单、1 条注销记录。发布须备份、校验 035 只新增表、保留原发布条目、验证旧 App 能获取 21700 且新版本不重复更新。

阿里云没有已配置的 EventBridge Token/API 管理凭据；当前浏览器也无可复用 CDP 连接。本轮不重启用户浏览器或宣称异步回执已接通。SMTP 明确无效地址冻结与其它修复可独立发布；异步事件依[配置说明](../deployment/invalid-email-events-candidate.md)后续接通。
