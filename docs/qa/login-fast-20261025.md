# 快速登录候选验收

2026-10-25，本机实现与验证完成，**尚未上线**。维护 `C:/DeiteriumAPP-IX/.worktrees/login-fast` / `xiwanzi/login-fast`，基于 `32f3e94`。范围和别名语义见[计划](../plans/login-fast.md)，构件与上线前置见[交付记录](../deployment/login-fast-candidate.md)。

## 实现结果

- 已知平台登录别名＋正确密码直接完成本地认证；新名字/本地凭据不匹配才同步查官方。重复检查同一哈希只计算一次，同一 userId 的失败保护不因切换别名或外部接口故障失效。
- 成功登录只向有限后台队列提交 userId/UUID，不携带明文密码或 token。单工作线程、128 队列、最多 512 条待执行/冷却记录；排队和执行中不重复，完成后十分钟内合并、失败后一分钟由后续登录重试。服务关闭会取消并等待该工作线程退出。
- 会话提交事务内复核登录别名、账号状态和密码，避免密码计算期间改名造成旧映射签发会话。后台改名保留平台主体、UUID、昵称和会话，未验证账号不会获得游戏权限。
- 官网中英文和客服账号入口立即打开，后台恢复不覆盖输入；可见性/聚焦刷新三十秒内合并。三个实际 `account-session.js` 与读取时公网摘要一致，认证/Cookie/CSRF协议未改。

- 官方改名、名字复用、迟到证明、未验证资料、身份冲突、队列和新快速登录的 24 项集成/竞态回归通过（106.618s）。最终补充实际密码错误＋上游故障保护后，9 项快速登录/队列 `-race` 测试通过（59.046s），包括 HTTP 入口对照。
- 身份回归中的别名共享失败预算、并发首次登录/改密、禁用、会话升级/撤销、来源/CSRF/管理员隔离和旧 QQ 兼容通过。原邮箱注册→游戏绑定测试曾失败；在未修改的 `32f3e94` 同样复现，原因是测试把真实官方玩家资料与合成 Core UUID 混用。将该测试供应商固定为同一合成 UUID 后，绑定和三种验证码密码输入回归全部通过（21.132s），没有放宽生产 UUID 校验。

## 耗时证据

同一真实 HTTP 测试服务器、真实 Argon2 密码计算，官方查询模拟固定延迟 1.5 秒：

| 路径 | 普通测试 | 最终竞态测试 |
| --- | ---: | ---: |
| 已知 ID / Web | 72.30ms | 92.63ms |
| 已知 ID / App | 64.66ms | 89.78ms |
| 新 ID 首次查询 | 1.575s | 1.603s |

另一测试将 UUID 查询一直阻塞，正确本地凭据仍在 59–87ms 返回；随后释放查询，名字更新且原 token 仍属于同一 userId/UUID。证明普通登录不再依赖外部请求结束，而非只减少一段固定等待。以上为本机测试，不是生产网络速度或真机体验承诺。

Playwright 实际浏览器对官网中文、英文、客服三个入口分别保持会话 GET 未完成，点击后弹窗即时出现；输入账号后释放 GET，输入内容保持；关闭重开能显示已恢复账号。连续各十次 focus/visibility 事件仍只有一条会话 GET。两轮打开弹窗为约 10–25ms；这是本机简化页面的行为测试，不是线上整站渲染测量。没有改布局和样式。

## 限制与上线状态

允许已讨论的本地登录别名短暂滞后；未知或复用名字仍需同步核验，后台失败按后续登录/进服事件重试，不承诺官方即时归属。既有强密码计算参数未降低，用户网络和高并发排队仍会影响总时长。

本轮未恢复部署连接，未推送或部署；线上速度尚未变化。原临时 SSH 连接文件已不存在，需恢复部署连接后按交付记录完成新生产基线、备份、切换及公网验证。没有修改真实账号、发邮件、重启游戏服或更新游戏资源。

完整本机日志与回执位于忽略目录 `output/login-fast/`；早期失败记录保留，最终验证以对应通过的竞态/回归日志为准。
