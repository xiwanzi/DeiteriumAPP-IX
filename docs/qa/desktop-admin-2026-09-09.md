# PC 官方管理与商品体验验收

2026-09-09。基线 `251ac68`，分支 `feat/desktop-admin-experience`；**Web 2.0.5 候选与配套 Go 已完成本机实现、构建与验收，尚未推送、合并或部署。** 线上网站仍为 2.0.4，App 仍为已发布的 2.0.5。工作区 `C:/DeiteriumAPP-IX/.worktrees/desktop-admin`。

## 本轮实现

- 官方管理使用独立侧边导航，直接进入商店、介入、公告、审计、邮件提醒和 Core；支持浏览器前进后退及未保存保护。管理页扩大 PC 可用宽度，窄屏导航沿用折叠模式。
- 商品改为带封面、状态、分类、价格和库存的表格；支持已加载内容关键词/状态/分类筛选、每页 12 件与继续加载服务器后续结果，明确显示加载数量，不将首批数据冒充全量。
- 商品编辑为宽屏双栏，底部固定保存操作；草稿保存后继续编辑，保存并发布复用同一草稿版本。发布失败明确区分草稿已保存与发布未确认，重试保留原请求编号。上传支持拖入图片、原图尺寸、图片说明和封面调整。
- App 模拟预览提供 360 / 393 / 430 dp 屏宽及浅深色，展示商品详情、推荐海报、双列卡片、购物袋。单独的裁切页面显示原图像素、居中保留区域、左右/上下裁去量、画面保留比例。布局来自当前 Android 源码；没有改写原图或新增 App 不支持的裁切焦点配置。
- 商品可编辑游戏邮件纯文本标题/正文并预览。发布后仅影响新订单；成交时写入持久邮件计划。单种商品使用其文案，多商品合为一封分节邮件；过长在报价阶段拒绝，不截断、不重复发奖。无需数据库迁移或 Mail/Core 协议更新。
- 公共消息按身份异步补取资料头像，同玩家请求去重、每批最多 4 个。消息、最近参与者、侧栏和转账选人保留头像对象；加载失败回退姓名首字，换头像成功同步侧栏。公共历史与 WebSocket 连接独立加载。
- 商品详情改为图库与购买信息双栏，提供数量步进、库存/限购、交付说明；购物袋增加商品缩略图和横向条目；结算显示商品、领取账号、准确服务端金额、报价剩余时间和明确付款确认。修复交付地点变量遮蔽浏览器 origin 导致恢复请求身份不完整的问题。

## 验收边界与发布准备

手机预览模拟当前布局，dp 与源图 px 分别标示；实际 Android 字体、系统显示缩放及游戏邮箱渲染仍需最终设备观察。网页管理表单可配置邮件，不等于已向真实玩家投递验证。

发布应配套更新 Web 和 Go：旧 Go 会拒绝新的邮件字段。保留现有账号、商品、订单及图片数据，无需 App 安装包或游戏插件更新。上线前备份网站/程序指向，按新目录发布并核对静态摘要与健康状态；不覆盖原版本目录。

若新字段已被写入商品，回退网页时应保留兼容新字段的 Go；不要直接退回不识别 `mailTitle` / `mailBody` 的旧 Go，更不能恢复旧数据库覆盖成交记录。需要回退业务实现时保留新增字段解析能力。
