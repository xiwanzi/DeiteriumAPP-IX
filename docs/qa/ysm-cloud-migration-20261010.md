# 模型管理迁移验收

源码基于当前线上 App 2.0.24 / Web 2.0.33 的主分支继续；新的 Web 版本为 2.0.34。本文记录隔离验收，不表示已部署。

- 实际 Go → Velocity → Rust Cloud 链路完成约 729 KiB 模型发布、撤下、恢复、不同内容 v2 和回滚到旧内容 v3；不是模拟接口或静态成功提示。
- 桌面和 390px 窄屏检查；深色界面无横向溢出，编辑/请求期间保留状态，失败不被刷新清空。
- Go YSM 路由、权限、上传代理、实际审计写入与会话撤销测试通过；浏览器集成使用本机独立 MariaDB 临时库，未在生产创建测试账号。
- Web YSM 的 5 项请求与权限测试通过；当前主分支上的 Vite 构建通过，保留已有大 chunk 提示。
- 游戏侧另行使用当前生产相同核心的 Youer/Velocity、双实际客户端及单正版账号验证；完整模型库 283 个，NPC 动作/重生/维度切换、增量版本、S3 失败直传、损坏缓存修复和 Cloud 重启已有实机记录。

发布需配套新的 Cloud、Velocity 网关、Sparkle 桥与 CitizensYSM，并先保留旧程序、私有配置、NPC/玩家状态与客户端分发清单。不能单独覆盖当前 Go/Web 而遗漏游戏侧配置。实际源码提交、远端备份、切换时间和线上验证另写部署记录。
