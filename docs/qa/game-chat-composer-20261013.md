# 游戏详细聊天页：回到底部与回车聚焦

2026-10-13，本机候选已完成，尚未发布。基于事件同步候选 `a6b2fbf`，仅修改游戏聊天客户端；App/Web 和服务端不在本次界面改动范围内。

## 行为

- 世界、附近、团队和每个私聊会话统一使用详细聊天页。
- 离开底部时，在加号右侧显示小倒三角；回到底部后隐藏。点击立即将当前滚动位置与目标位置归零，并聚焦输入框。
- 在上方阅读时收到新消息继续保留阅读位置，不强行拉到底部。
- 输入框未聚焦时，回车只聚焦，已有草稿不发送；聚焦后按回车，有内容才发送。主键盘和数字键盘回车均支持。
- 长按回车不把“聚焦”和“发送”连续触发。没有输入框的私聊列表页不发送隐藏草稿。
- 图标使用原工具栏间距与悬浮反馈，小三角由 ShaderTexture 在实际分辨率抗锯齿绘制，不添加常驻文字或大提示框。
