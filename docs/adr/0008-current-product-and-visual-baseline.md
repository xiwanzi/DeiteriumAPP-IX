# ADR 0008：新版产品与视觉基线

## 状态和来源

Accepted（记录用户已明确的决定），2026-09-08。

依据：[指定任务](codex://threads/01a07858-873a-7e71-a2f2-36826f9d698f) 的 04–07 版确认。本 ADR 记录已经发生的方向调整，不将进行中的实现宣称为完成。产品细节见 [新版 PRD](../prd/deuterium-current.md)。

## 决定

1. 继续原生 Android 与 Kotlin + Compose。ADR 0001 技术选择保留，但默认 Material 3 外观被新版视觉要求替代：iOS / HyperOS 方向的分组列表、胶囊操作、浅深色与自定义控件。Material 3 文本、表面和语义色等基础设施仍可使用。
2. 导航为商城、市场、信息、我的。钱包进入我的，AI 进入信息；商城、玩家市场、私聊、委托已是新版范围。
3. 系统/浅色/深色主题替代动态取色与彩色主题。柔光玻璃用于导航和浮层并分别开关；主内容清晰，顶部模糊连续向透明过渡。
4. 旧 Mastercard 动画被蓝色圆环与确认勾替代；07 增加前置模拟扫脸，只是体验反馈，不是真实生物验证或支付服务。
5. 先交付体验 App 和详细接口契约；官方商家与平台管理网页端随后实现。旧“只有三个模块”“不做私聊”“不做任何 Web 后台”不再限制已确认范围。
6. 既有 Android → 后端 → 插件桥、安全身份和经济权威边界继续适用。新增担保冻结和委托不靠客户端直接改服务器余额实现。

## 影响与未决事项

旧 PRD 和 01–06 计划保留历史语境，冲突部分按最新确认覆盖。不要删除旧协议、安全规则或兼容能力来迎合视觉改版。

第 07 版完成状态、新后端实现、跨设备联调和生产发布分别验收。生产更新地址、正式发布签名和迁移方式不能由本 ADR 推断。
