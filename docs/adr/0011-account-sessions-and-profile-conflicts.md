# ADR 0011：长期 App 会话与未验证游戏身份冲突处理

状态：Accepted（2026-10-14，用户确认）；本机候选已实现，未发布。

## 决定

保留 Go＋MariaDB、稳定平台 userId/playerRef、现有密码和业务归属，不引入 Keycloak/Auth0、JWT 替换或 MFA。公开正版资料、平台凭据与游戏所有权继续分离。

App 原生会话取消按时间到期；网页会话为签发起 30 天，保留撤销、改密和封禁失效。启动器的微软游戏登录沿用已有刷新机制，内嵌社区属于网页会话；不能把两者混为一个平台 token。游戏聊天专用令牌继续短期、权限受限。

正常未验证登记不设置完成期限，也不自动释放或删除，允许玩家等待两三个月开服。对于已核实的冒领/占用，只由超级管理员解除**未验证登记**，保留原平台账号和邮箱恢复入口；已验证 UUID 不开放解绑或换绑。

真正持有人需有可信游戏会话验证码或客服核实的可靠所有权证据。公开名字、UUID、截图不能单独作为依据。解除后为经核实邮箱保留继续注册的路径；新注册仍需邮箱验证及原游戏绑定流程，不继承原登记者账号或资产。

原登记者通过邮箱登录，可在已解除登记状态下填写自己的正版游戏名。所有处理带管理员密码确认、证据引用、幂等请求和审计；未完成认领时可审计地更正邮箱，已创建账号不能通过更正功能移交。

## 容量边界

约百人同时在线与集中进服是目标。官方查询统一受限、短时排队并合并相同在途请求；密码计算保留原内存并发上限。平台登录高峰与游戏通行检查分开使用请求预算，游戏进服检查不等待这些外部查询或密码计算。

账号失败保护与来源流量限制分别维护；正常成功和基础设施繁忙不作为密码错误。参数依据隔离测试，不能将本机模拟结论当作真实百人进服证据。

## 代价

永久会话需要可撤销设备管理；原程序回退必须处理新增会话列与身份预留规则，不能直接换回旧二进制或恢复旧整库。当前未做真实玩家认领、生产迁移或发布。
