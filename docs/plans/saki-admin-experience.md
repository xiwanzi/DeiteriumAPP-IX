# 账单、Saki 与管理体验

2026-09-09。基于已上线 App / Web 2.0.5，落实本轮用户要求；本文件是实施边界，不是上线记录。

- 账单完整显示收支金额，根据可用宽度和字体缩放切换双列或上下排布；保持现有浅深色与原生样式。
- 平台管理员可分页搜索全部账号、授予或撤销平台管理权限、封禁或解封。封禁撤销登录会话；不得自行封禁或撤销自己的权限，不允许删除最后一个可用管理员。每次修改校验版本并留下审计记录。
- 小祥设置管理套餐名称、说明、信用点价格、额度、重置小时数、有效天数和开放状态，以及系统提示词、知识条目、模型、联网与生成参数。保存使用版本检查；凭据沿用服务器私有配置。未主动开启售卖前继续禁购。
- Saki 购买复用现有信用点托管和结算机制，按固定请求标识恢复未知结果。仅在结算成功后一次性授予套餐权益；订单保留购买时的名称、价格、额度和时长，不随后台改价变化。按购买时长计费，不自动续费。同套餐续期累加有效期；已有其他付费套餐时到期后才能更换，避免覆盖剩余权益。
- Saki 记录属于商城订单，商店显示 Saki AI，头像复用小祥，联系卖家返回 AI 聊天。没有邮件领取与退款入口，后端同样拒绝退款；支付成功留在套餐页并刷新权益。
- 官方商品订单保留未领取可退款、已领取不可退款规则。内部交易步骤仅用于审计；只在需要用户处理或有最终结果时生成提醒。提醒另带是否系统提示的属性，到账必须来自已成功的资金回执并防重复。
- 网页操作组统一间距、换行和输入框布局；新增管理页沿用现有侧栏、表单和弹窗。

验证覆盖权限拒绝、账号封禁后会话失效、并发修改、套餐配置版本、购买关停/价格变动/额度与到期、重复付款/未知结果恢复/拒绝退款、通知降噪与收款人隔离；执行 Go 集成测试、Web 测试和浏览器检查、Android 构建及必要的原生界面验证。隔离测试不写生产资金。

迁移只新增字段和表；上线前备份数据库。新套餐订单产生后，回退需保留 Saki 识别与退款拒绝，不能用旧数据库覆盖新记录。

设计参考：[Apple In-App Purchase](https://developer.apple.com/in-app-purchase/) 的价格、服务与时长说明，以及 [Apple Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts) 的简短文案与清晰操作。
