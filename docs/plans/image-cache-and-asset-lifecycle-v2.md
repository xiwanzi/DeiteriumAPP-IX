# 2.0.1 图片缓存、存储空间与 OSS 生命周期

日期：2026-09-08。状态：实施中，构建和发布证据另行补充。

## 本轮确认的规则

用户最新要求覆盖初稿：历史订单继续复用商品原图，不为每个订单复制图片。图片进入历史用途，并且不再用于在售商品、有效委托或其他当前业务后，才转入专用到期前缀。旧头像、放弃上传和完全废弃图片也进入该前缀。雨云按对象在该前缀下存在满 30 天后异步删除。订单文字、金额、操作记录继续保留。

在售商品与历史订单共享同一个 assetId。不会因为一笔订单结束就给在售原图启动倒计时。倒计时从对象转入回收前缀开始；当前用途全部结束后才发生此移动。

本轮用户授权实现 Android 和后端、发布 2.0.1，并更新 App 在线更新入口。APK 沿用当前包名和签名，覆盖安装保留账号和业务数据。Android 系统安装确认仍由系统处理。

## Android 缓存与存储空间

- 统一单例 Coil 图片加载器，选择与工程现有 Kotlin/Compose 版本兼容的 Coil 3.3.0，不升级整套 UI 依赖。
- 内存缓存最多 32 MiB，且不超过应用最大堆的 10%；磁盘总预算最多 200 MiB，空间较少时缩减。LRU 按字节淘汰。
- 缓存按服务 origin、登录账号、不可变 assetId 隔离，SHA-256 用于完整性校验。签名 URL 不作为 asset 内容身份，换签不重复下载。
- 持久磁盘命中在签名解析前完成；图片按控件尺寸解码；同对象下载合并，网络并发最多 3。
- 上传完成后直接缓存已有图片字节；当前头像从保存的 assetId 在启动时预热。切页缓存命中不重复淡入，不主动清空有效列表。
- 下载流式写入并校验后提交，损坏缓存重取。清理/换账号使旧请求失效，避免晚到的响应写回；账号间图片不可串用。
- 链接过期按原业务 GET 路径自动重新授权，保留 20004 修复的“他人图片不走仅所有者资产接口”边界；最多重新授权一次。
- 后端返回图片已过期时，显示占位并保留订单其余内容；retention 截止时间与下载签名期限分别处理。资源重新激活后不延续旧回收截止时间。
- “我的 → 存储空间”使用真实文件统计，iOS 风格分组与占用条，支持图片、更新文件、临时缓存分类清理与全部清理。应用、账号设置、聊天/交易记录、上传草稿及当前资源包保留；下载、验证、安装中的更新文件受保护。
- 缓存容量淘汰、用户清理或系统回收后可以重新下载，不承诺永久只下载一次。

## Go 资产生命周期

仅使用当前配置的对象前缀范围。测试桶中：

| 对象前缀 | 含义 | 规则 |
| --- | --- | --- |
| deuterium-test/uploads/ | 当前有效资产及现有上传 | 不整体设置过期 |
| deuterium-test/gc/ | 已无当前业务用途，允许到期删除的资产 | 存在满 30 天后删除 |

不会新增每订单 history 图片副本。数据库维护资产生命周期、原/目标对象位置、转入时间、保留截止时间和重试信息；业务绑定继续指向原 assetId。

候选判断需要核对头像、商城草稿/发布内容、市场、委托、订单快照和争议证据。进行中的订单、委托、资金未知或未结束的退款/介入仍算当前业务。临时下架后再次上架的图片，在重新投入使用前必须恢复至有效前缀；已过期的图需要重新选择，不靠旧 URL 或本地缓存复活。

资产锁与业务事务防止新增引用和回收同时成功。OSS 网络操作在短事务之外执行：记录任务 → 服务端复制到唯一 gc key → 核验副本 → 切换对象位置 → 删除原 key。复制失败保留原图，原 key 删除失败重试同一任务；避免重复复制重置对象年龄。已发出的上传授权要先到期，防止旧 PUT 在原 key 删除后重新创建对象。

无引用的 READY 上传保留编辑恢复宽限期（建议 72 小时）；替换头像等旧资产进入有界后台任务。异步删除后保留资产元信息和业务记录，读取降级为图片过期，不能令整个订单接口失败。重新上架未过期图片时，先核验恢复到有效前缀再允许新引用；恢复和到期删除竞争失败时不得报告恢复成功。

用户已确认雨云生命周期能力。上线前用隔离对象核对 CopyObject、内容摘要和复制后的 LastModified；规则仅匹配确切 gc 前缀。旧桶对象按业务引用核对后分批处理，不清除用户新增业务数据。

## 验证和交付

Android：签名变化不重复下载、进程重启磁盘复用、同图并发合并、损坏/中断恢复、清理与下载竞争、账号隔离、空间统计及安全清理；浅深色存储页和返回/清理交互；覆盖安装和原签名验证。

Go：有效商品与历史订单共享不回收，最后当前引用结束才入 gc；委托/未结算/争议保护；换头像、无引用上传、恢复上架、复制/删除超时重启恢复；过期图片不破坏订单接口；真实数据库并发回归。

交付：2.0.1 APK 与 SHA-256、源码提交、测试证据、服务端部署与回滚记录、在线更新清单、公网完整下载及旧版本更新检查。实际发布前不将版本号变化写成已交付。
