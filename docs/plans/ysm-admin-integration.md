# YSM 管理整合

2026-09-28。用户已确认统一栏目、界面和登录，在现有管理后台直接操作 CitizensYSM。基于 `df8f8df`，复用已完成发布的 `chat-domain` 工作区，新分支 `xiwanzi/ysm-admin-integration`。

## 已确认范围与边界

- Web 增加 `/admin?section=ysm`，使用现有后台导航、组件、主题和 Deuterium ID 会话，仅 `platform.admin` 可访问。
- 模型列表、搜索/分类、详情、增删替换、节点状态、任务重试、差异、审计、存储配置、空间回收与诊断复用 CitizensYSM 的 HTTP API。
- Go 只做鉴权与受限接口适配。Velocity 继续作为配置、模型清单、暂存、签名发布、回收与节点收敛的唯一权威；不复制模型库、不直连其数据库。
- 原管理服务只监听回环。跨机器用受限 SSH 隧道连接；Go 只接受配置中的字面回环地址及回环 Host/Origin，不公开原免密端口，不传递浏览器 Cookie/Authorization 给 YSM。
- 每次预览独立取得上游 CSRF，与确认令牌一起加密封装并绑定当前登录会话和动作，不跨会话共用；模型修改保留预览、版本校验和一次性确认。发布超时视为结果未知，不自动重试。
- 提交前在现有管理审计记录操作者、请求标识和动作，不记录密钥或文件内容；YSM 原审计保留。
- 本轮先完成本机实现和验证。生产隧道、配置变更、Web/Go 发布与真实模型操作须依据本轮后续发布授权；不改游戏模组。

## 验收

验证权限、撤销会话、CSRF/来源、端点白名单、上游凭据隔离、超时、不同会话确认隔离、上传限制和中文模型 ID。检查 Web 构建、主要操作流程、浅深色和窄屏。用本地夹具验证写操作；生产只读检查与生产上线另行记录。
