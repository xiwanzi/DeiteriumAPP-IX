- 官方商城使用 App Store 式展示；玩家市场、委托大厅、钱包在网页上独立进入一级导航，另有信息、我的。

- 用户随后指定复用任务“寻找相似产品参考方案”的现有素材，禁止继续生成图像。

## 实施边界

第一版交付本机浏览器交互与统一组件，不将其写成后端已接入。UI 状态统一保存在浏览器，货币以整数分表示；演示交易保留快照、动作幂等和作用域检查。生产身份、权限、资金、推送和 AI 均须未来经共用 API 获得。

功能与未完成项以 [web-app README](../../web-app/README.md) 为准，后端契约不会被此演示实现反向改写。封禁交易接管规则中仍未确认的细则保留讨论状态。

## 失败与恢复

- 余额不足、库存变化、自买自接、重复付款、重复确认、越权和封禁返回明确反馈；不更改失败前状态。
- 本机存储超限拒绝本次写入，提示缩小上传图片，不假报保存成功。
- 浏览器返回、刷新和深色/系统主题保留正确路径与已保存状态。
- 桌面与手机均检查横向溢出、弹窗、键盘、素材加载及减少动态效果偏好。

后续使用确认后的后端契约接入，并核实 IP、测试端口、TLS 和反向代理后再进行生产服务器测试；本轮未部署。
