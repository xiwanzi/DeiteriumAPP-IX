# 游戏内 LDLib2 聊天实施边界

2026-10-11 用户授权本机游戏实现，未授权生产发布。基于 chat-media e950bec 建立独立工作区。

- 采用 NeoForge 1.21.1 + LDLib2 2.2.39，独立替代聊天客户端；不篡改第三方 ModernChat JAR。
- 对照 Web V12：世界/附近/团队/私聊、联系人、图片查看、个人贴纸、富文本交互；T 与 / 为薄快捷栏，Enter 开完整聊天，去掉屏幕常驻 Enter 提示。
- 消息头顺序：单色粉色 ID、固定头衔「封弊者」、后缀。世界使用 Amiya（兼容 Aamiya）、Login→封锁区、Odyssey→残像区域、Mek→科研中心。附近/私聊/团队只用频道后缀覆盖服务器位置。
- 附近 50 米，由服务端同世界距离校验；私聊与团队只传授权接收人，不向其他客户端广播后再隐藏。
- App 公屏正文只保留消息内容，不重复拼接玩家 ID、服务器或 App 前缀。身份单独结构化显示，不用正则剥离任意用户文字。
- 复用 Go 媒体、贴纸授权与 S3。游戏不含节点密钥；游戏身份由 Core 认定后签发短期聊天限定凭据，不能访问资金/管理接口。不自动创建/恢复已清理账号。
- 压缩沿 App 契约，后台有界队列；网络/解码/磁盘不在渲染线程；纹理在渲染线程有限提交。消息增量更新，缓存有界，退出/切服取消旧会话任务。
- LDLib2 负责本地展示树，数据经独立聊天协议进入本地模型；不使用 LDLib 的服务端数据绑定或物品 Menu 同步。
- 独立 Agent 对照预览逐 UI 审阅，真实游戏截图、构建和性能证据分别记录；不将浏览器验证说成游戏验证。
