# 注册验证码与登录浮层修正

2026-09-11，用户确认：获取注册验证码不依赖密码；登录页“忘记密码”采用应用内统一的浮层玻璃样式。

- 验证码请求只需游戏 ID 和 QQ。保留服务器权威 UUID、在线检查、身份/QQ 占用检查、发送限次、验证码失效与一次消费规则。兼容旧客户端附带的 `password` 字段，但忽略它。
- 创建账号时仍要求密码为 8–64 个字符；密码不进入验证码生成或投递流程。
- Android 注册页不再随验证码请求发送密码；游戏 ID、QQ 和提交注册时的密码错误给出具体提示。
- 登录页为现有 `IosSheet` / `SoftGlassSurface` 提供页面背景采样，继续使用全局浮层开关和材质参数，不单独提高默认不透明度。
- 本轮不处理旧号注销，不修改用户数据，不自动发布 App 或部署后端。

验收覆盖无密码取码、旧请求兼容、注册密码校验、验证码消费/限次、Android 编译，以及浅色/深色、玻璃关闭和键盘打开的登录浮层。
