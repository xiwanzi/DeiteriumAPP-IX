## 数据与权限

“商家端”在本任务指统一官方管理站。全玩家交易查询只授予平台审计权限；普通商家只可看本店订单，不能通过 playerRef 查询其他店或玩家市场的全局流水。

统计定义：已出售金额为玩家市场已付款成交原额扣除实际退款，包含尚未释放的担保；另列成交原额、退款、已结算、担保中。未付款取消不计，部分退款准确抵扣。委托和转账独立分类，不能混成商品销售额。每一行可下钻同一范围内的逐笔交易，支持角色、渠道、状态、日期与搜索，导出遵守相同过滤与权限。

生产统计必须由后端计算全部匹配记录，不能前端只汇总当前分页。缺少接口的部分先交付可操作演示和可验证契约增量，标明未实现状态。

公告支持草稿、编辑、预览、发布、撤下、置顶与发布时间；玩家端只显示已发布版本。编辑已发布公告形成新草稿，未经再次发布不覆盖公开版本。正文渲染为文本/受控内容块，不执行 HTML。

## 界面与验证

聊天使用应用侧栏、会话列表、全高消息区、可收起详情栏；会话搜索、消息搜索、草稿、引用、已读位置、发送反馈、滚动到最新、快捷键和移动端返回。已连接模式遵循 Foundation 对引用/提及暂不支持的限制。

登录使用统一 Deuterium ID、明确标签、显示密码、错误与重试、注册/找回切换；真实 token 仅 HttpOnly Cookie，CSRF 仅内存，退出清理会话与实时连接，不保存真实密码。
