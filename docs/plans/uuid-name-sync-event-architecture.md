- 正版网络查询独立限额，密码计算名额只围住 KDF，不等待网络或数据库事务。
- 游戏进入/离开主动通知 Core 连接；重连和低频名单校准补偿遗漏。Go 比较已认证会话差异，无变化不写库；名字核验只由变化触发，失败任务单独退避重试。

- 通知按公共频道、用户、名称、账号、配置分发。Web/App 复用连接，首次/重连拉取基线，其后按变化获取单个会话或名称增量；保留持久游标和低频消息恢复。
- 通用 HTTP/WebSocket 编码器不再解析、遍历和改写任意 JSON。聊天使用类型化玩家字段批量解析；交易只更新明确的展示参与方，历史快照保持。客户端名字映射限于明确展示字段，页面无变化时保留对象引用。
- 不移除心跳、失败退避、结果未知恢复或其他业务必要任务；不引入新的中间件。
