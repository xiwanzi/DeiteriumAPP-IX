# 2.0.3 修复与发布

2026-09-09，用户已授权修复、优化并发布推送 2.0.3。基于私有仓库 main 419892b，修改 Android 与必要的 Go API，不更换游戏插件或网站。

## 已确认范围

- 商城/市场付款统一为简单二次确认弹窗，只显示“是否支付 ×× 信用点？”和取消/确认付款。用户后续要求覆盖先前商品明细方案，不列商品清单、库存或报价说明；内部继续校验权威商品金额和使用原幂等流程。
- 新商品网络图片用于加购动画、搜索缩略图；搜索建议来自真实目录，移除演示品牌关键词。
- 公开委托大厅只显示仍可接取的有效委托，历史记录进入我的委托。结束的订单/委托及下架或售罄的自有市场商品提供删除记录。
- 删除为账号级隐藏：持久化独立显示偏好，不删除订单、资金、退款、邮件、证据或对方记录。只允许当事人，拒绝进行中/资金未知/退款处理中/平台介入中的交易。未来重新进入活跃状态的业务必须重新显示。
- 联系人和信息入口增加精简红点，按服务端未读数更新，实际阅读后推进已读位置；不能因同步历史就标记全部已读。
- 公告和 AI 正文支持原生 Markdown，保留长按操作与链接访问；不使用可执行 HTML。
- 公共消息发送与历史同步解耦，重连期间可用同一鉴权/幂等入口提交，成功只依赖持久接受回执。未知结果继续保留原消息键。

## 数据和发布边界

新增迁移 019 只保存按用户隔离的记录隐藏标记。公共发送 HTTP 入口复用现有鉴权、频控、节点可用性、持久消息及重复检测；不改变资金协议。App 版本 2.0.3 (20300)，沿用已安装测试签名。

验证覆盖：复现/回归加购动画和搜索、浅深色 Markdown/红点/删除入口、价格确认和幂等、历史状态过滤、用户隔离/终态隐藏、公共消息回复/提及及 HTTP/WS 同键重放。使用隔离库与测试夹具，不创建生产付款。发布前备份程序、数据库和更新清单，核对迁移摘要、健康、下载与签名，按既有账号更新通道向用户推送。
