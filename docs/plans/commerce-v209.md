# 商城 2.0.9：结算修复、交付与优惠

2026-09-10，依据本轮用户要求；开发基线为 2.0.8 发布源码及其部署记录。本文记录实施边界，不代表已发布。

## 已确认范围

- 支付页使用本次订单的店铺名称，购买成功后移除购物袋内已购买的数量，失败或结果未知时保留，恢复原订单成功后同样处理；保留支付期间新增的商品。
- 商品仍选择一个交付模板，模板可组合多个精确物品版本及数量。物品、模板选择支持搜索、分页、已选摘要和移除，不依赖长下拉列表。
- 商品可附带整数信用点，与实物一起交给独立 Mail 发放；修复 TACZ 等带组件物品在邮件中的预览，实际附件快照保持完整。
- 商品独立配置折扣，以及单笔、每玩家累计、每日、每周、每月限购；可同时生效。每日默认北京时间 00:00；每周可指定星期和时间，每月可指定日期和时间，不存在的月日按当月最后一天。
- 管理端“店铺与运营”增加优惠券；全员或指定玩家，有起止时间，全员券在有效期内覆盖后来注册的玩家。玩家仅展示有效且未使用的券，过期后消失；历史订单仍保留优惠快照以便核账。
- 券可限定店铺、商品，两者同时指定时取交集。整单券支持满减、满额折扣及折扣优惠上限；单品折扣券作用于一件优惠最大的可用商品。
- **用户已确认每单只使用一张最优惠券**。“可叠加”仅表示能否与商品折扣同享；不叠加时比较原价用券与商品折扣的最终总额，选择更优惠的结果。
- App 购物袋二级页右上角增加优惠券入口，保留左上角返回及现有主题、玻璃、支付动效。价格展示实付、淡色划线原价和优惠摘要。
- 用户补充：“我的”页面原历史账单快捷入口改为“我的优惠”，打开同一优惠券页；历史账单保留在钱包内，设置搜索中的账单入口也归入钱包。
- 用户追加：新券到账支持进入 App 后的合并浮窗、前台轻提示与“我的优惠”红点。复用现有玻璃材质和动效；单张且规则简明时只显示“好的”，多张或需要展开适用规则时增加“去看看”。
- 用户进一步明确：编辑好的优惠券先保存为草稿，在草稿列表勾选多张、批量发放。一次发布形成一个稳定批次，不再逐张点击后立即发放。

## 实施决定

- 金额使用整数分及精确比例，服务端负责报价与提交复核。商品折扣以支付比例（万分比）保存，10000 为原价；优惠金额明确四舍五入到分。
- 每个活动每玩家一张一次性券；不需要玩家领取。已成功使用的券不因退款再次发放，明确失败的支付释放券，结果未知继续占用。可创建新活动再次发放。
- 限购按资产 UUID 统计，包含处理中订单，明确付款失败或完整退款释放额度；跨日按创建订单时间归属。已有真实订单一并计入，删除展示记录不改变计数。
- 优惠报价为短期快照，提交时重新核实商品版本、券资格/有效期/占用、限购与交付。优惠变动要求重新确认，不能悄悄增加扣款。
- 沿用现有同店铺订单和邮箱领取范围规则，范围不兼容需分开结算。
- 信用点只作为已发布商品的交付内容，后端与客户端不直接写游戏经济表。Mail API 以兼容旧调用的方式扩展，领取幂等与撤回互斥仍由 Mail 负责。
- 数据迁移仅新增配置/使用记录和必要索引；保留所有已有业务与线上配置。回退程序前停用新促销与含信用点的新商品，保留新订单及迁移表，禁止整库覆盖。
- 新券提醒按账号资产 UUID 和券 ID 保存“已提醒 / 已查看”，只由展示或查看触发确认，读取不消耗提醒。当前有资格且未使用的有效券才参与；新注册玩家适用同一规则，修改旧券不重复发放提醒。客户端按服务器时间去除到期券；确认失败保留本机待同步记录，重试仍使用同一批券 ID。
- 启动/回到前台的新券合并展示；等待启动完成、键盘关闭及其他浮层退出，不打断付款。前台后续新增使用可点击的玻璃轻提示。“好的”关闭复杂摘要时保留红点，简明券已完整展示则标为查看；进入优惠页后只确认实际加载到的券。
- 新建券始终为草稿，保存/编辑草稿不触发权益或提醒。发布时锁定所选草稿、核对版本、受众、范围与有效期，在一个事务中全部发布；任何一张校验失败均不部分发布。每次最多 100 张，重复提交同一发布请求返回同一批次。
- 券保留各自的优惠规则、受众和有效期。同一批次对某玩家最多提醒一次；同批未来才生效的券届时正常出现与计入未查看红点，不再次弹窗。玩家只看到自己有资格的券，过期成员不显示。已发布券可停用/编辑，不能通过重新选中草稿重复发放同一张券。

## 设计依据

- [Apple Alerts 指南](https://developer.apple.com/design/human-interface-guidelines/alerts)：参考简洁的信息层级、清晰的操作按钮与避免重复打扰；本次沿用 App 的玻璃浮层样式。
- [Apple 购物付款说明](https://www.apple.com/uk/shop/help/payments)：参考购物袋到结账的层级与礼品卡呈现；没有把礼品卡误认为同规则优惠券。
- [Shopify 优惠组合](https://help.shopify.com/en/manual/discounts/discount-combinations)：参考商品/整单分组、叠加开关和最优优惠。
- [Shopify 商品选择](https://help.shopify.com/en/manual/discounts/discount-types/buy-x-get-y)：参考搜索与浏览选择器。
