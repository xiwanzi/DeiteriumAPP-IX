# 注册与登录完整审查

用户要求完整检查社区、App、官网及客服中心，重点修复正常 ID 的倒计时复位和再次获取验证码提示频繁。

已确认：所有发码失败均被客户端当作“可立即重发”；服务端共享发码 IP 配额在查 ID 前消费，查询失败也占 15 分钟内 10 次发码额度；统一错误只返回 60 秒，无法表达剩余冷却或 15 分钟/每日配额。修改资料和切换页面还会丢掉同邮箱的冷却状态。

修正边界：保留现有实际发码安全限额，在发码数据库事务成功后才消费；缓存未命中的正版查询另用有界配额。邮件冷却、每日额度及 IP 限额返回真实剩余秒数，前端按收件人保留冷却，对已知无效 ID/未发码错误开放重试，对限流维持等待，对网络未知结果保留等待并提示检查邮箱。晚到响应不覆盖新输入。登录鉴权、7 天会话、CSRF、账号隔离和独立游戏验证保持。

验收覆盖完整有效注册→邮箱验证码→最终注册→登录/刷新/退出、错误密码/验证码/过期/重复与并发请求、限流/重发/修改邮箱或 ID/切换页面、邮件和查询失败、四个当前入口及旧客户端兼容。生产检查以只读和不投递邮件的受控探针为主；端到端注册使用本机隔离库和本地邮件，不新增生产测试账号。先取得完整证据再发布；沿用当前用户的推送、合并、部署授权。
