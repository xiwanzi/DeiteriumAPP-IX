# 体验版 09：版本标开屏、识别停留与平台介入

用户于 2026-09-08 明确要求本轮快速完成以下变化。继续在 `ui-lab` 交付可覆盖安装的 09；不改写正在独立开发的 Go 后端或网页工作区。

- 开屏和载入过渡换回版本徽标，覆盖 08 的图标选择决定；关于页/注册页仍用 App icon。
- 每次支付单独抽取 1–3 秒模拟识别时间，保持在识别画面，再进入现有翻转光环/确认动画及提示音。停留时间/截止点在重组与旋转时保留，不重复扣款；减少动态效果时仍保留识别等待，但不播放翻转动效。
- 市场订单及委托退款被拒后，将灰色退款入口改为“申请平台介入”。填写原因类别、10–3000 字事实说明、诉求、部分退款金额（对应诉求时）及可选凭证图片；自动附上不可编辑的原交易/退款快照，提交前再次确认。
- 沿用共用契约的申请、查询、裁决字段，并参考 `web-player-v1`、`backend-rewrite` 的现状。后端资金/介入业务仍待完成，本轮实现完整本机申请与结果体验，不声称已发送到真实管理端。
- 受理时原子保存案件并暂停未释放担保的倒计时。处理中禁止双方自行确认、退款或修改履约状态；重新打开/重启仍保持暂停。一个交易只保留当前案件入口，重复提交不创建第二案。
- 平台裁决可为全额退款、部分退款并结算剩余、结算给收款方、继续履约、不采取资金动作、已结算交易转人工处理。前三项由本机体验平台工具演示，实际接口仅管理员有权执行。资金只能处理一次，部分退款与结算之和不得超过担保；已结算交易不得再次退款或强制扣收款人余额。
- 继续履约/不采取资金动作时恢复原剩余时间，不重置整个时限；全额/部分退款或结算后展示实际金额与判决理由。平台退款不自行推断商品已退回，不自动回补已交付商品库存。
- “体验平台处理”放在详情末尾并明确是本机演示工具；普通玩家主操作只负责提交与查看，不能把其诉求当成平台结论。

验收：开屏徽标、支付随机停留范围及不重复提交；拒绝后入口、表单校验、照片读取期间不可提交、自动快照、案件/暂停持久化；全额/部分/结算/继续/已结算人工分支及重复裁决互斥。保留已有业务测试，新增与资金/计时相关的有效测试；构建、Lint、覆盖安装与元信息检查。
