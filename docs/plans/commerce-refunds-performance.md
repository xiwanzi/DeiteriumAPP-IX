# 优惠提醒、删除与启动性能修正

2026-09-11，基于已上线 2.0.9（20901）源码。当前仅本机开发，发布状态另行记录。

## 本轮确认边界

- 优惠券到账统一采用应用内顶部通知，启动和回到前台不再显示大弹窗。沿用批次去重、离线确认和“我的优惠”红点；关闭提醒不等于已查看。
- 平台管理员可删除草稿或已停用券。启用中的券须先停用；删除后从管理列表与玩家可用券中消失，不能再次启用或发布。
- 有商品发布权限的商店成员可删除商品，确认中说明同时停止销售。商品从经营列表消失，不能再编辑/发布；原订单、交付、退款、库存恢复与图片快照仍保留。
- 商城订单全额退款完成后恢复原券使用资格，包括实付为零的全额抵扣订单。退款未完成、失败、结果未知或部分退款不返券。按原券的有效期、受众和启停状态判定能否再用，不延长有效期或重新发放批次提醒。
- 通过新增幂等迁移恢复历史已全额退款订单的券资格，只移除对应券占用，保留订单、快照、提醒和批次历史。部署前备份；回退保留新状态与记录，不能恢复已被重新使用的旧占用。
- 性能优化以代码和本机测量为依据，保持当前启动、加载、主题与玻璃视觉；模拟器数据不能证明骁龙 8E 真机体验已改善。

## 验证范围

Go 覆盖角色/店铺权限、状态和版本冲突、重复请求、删除与下单互斥、删后原订单退款、返券重用及旧退款重放、过期停用与未知结果；运行隔离 MariaDB 集成测试。Web 检查删除确认、失败重试、列表移除及窄屏。Android 检查提醒点击/关闭/前后台与加载动画，并运行相关单测和构建。
