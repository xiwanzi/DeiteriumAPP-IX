# 体验版 06：交易细节与品牌体验

## 范围与用户确认

继续修改原生 Android `ui-lab` 与交付文档，版本 `0.6.0-ui-lab (6)`。正式 App、后端、插件及真实资金不参与。本轮使用用户提供的 Deuterium Logo，采用 iOS / Apple Pay 风格的界面与确认反馈，仍是 Android 本机体验，不接入真实 Apple Pay。

用户确认：建筑服务从卖家点击“开始施工”起计时，按卖家设置的预期工期自动验收，发布时必须提醒预留验收时间。普通商品发货后 72 小时自动确认收货。已发货的市场订单只能申请一次退款；拒绝或撤回也不恢复申请次数。

## 界面调整

- 顶部模糊从状态栏开始最强，在整个工具栏高度内连续减淡至透明，移除大段恒定模糊区域。
- 搜索进入独立、完整的搜索模式：固定搜索框/取消、键盘与结果分区，返回保留原列表位置，避免原页大标题与搜索结果交叉。
- 市场使用双列商品卡；常用分类横排，全部分类下拉展开分组。工程类与普通物品有明确标识。
- 发布保留标题、简介、详情，库存 1–999；图片最多 5 张，第一张标为首页封面，可删除、调整封面。
- 下架需要二次确认；重新上架进入已填写的发布表单，重新校验后发布，历史订单保留原商品快照。
- 登录/注册使用提供的 Logo、统一字号和留白、分组表单与清晰反馈。
- 支付统一为蓝色进度圆环连续完成并绘出确认勾，配轻提示与触感，不再拼接 Mastercard 动画。
- 聊天参考 Apple 信息的紧凑气泡、圆形头像、胶囊输入与内嵌发送按钮。联系人/公共聊天/私聊头像统一进入资料页，展示简介、上次在线、ID、QQ，提供消息、特别关心、转账三个操作。
- 我的支持编辑简介。活动入口进入多活动列表，按状态组织，各活动独立详情和报名；公告保持现有内容结构。
- 官方商城增加 Apple、NVIDIA、AMD 品牌商品与真实公开图片，用于多品牌商品测试，信用点价格仍为样例。

## 交易与时间规则

- 退款表单提交前二次确认；提交后进入独立退款状态页，显示进度、原因、申请/处理时间、卖家通知和下一步。交易通知分别记录接收人；本机当前接收人可收到系统通知和交易通知列表提醒。
- 申请已发货退款时消费唯一一次机会，并暂停自动确认倒计时。拒绝/撤回后继续剩余时间，仍不可再次申请；同意退款后结束倒计时并返款。
- 普通商品发货时生成绝对时间期限（72 小时）；工程类在开始施工时生成卖家指定期限。工程购买填写项目名称和工程地点，操作文案改为开始施工/确认验收。
- 到期且无待处理退款时自动结算一次；退款、手动确认和到期处理相互校验，避免重复返款/付款。
- 本机保存体验订单、发布商品、钱包与通知快照，恢复时按绝对时间补算到期状态。使用私有文件原子替换，不引入生产数据库或后台保活；可靠的进程外结算与跨设备通知仍由未来后端承担。
