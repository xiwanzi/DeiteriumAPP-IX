# 商城内容区第二轮设计

2026-10-08。用户在安装独立离线演示后，明确允许重新设计卡片、参考京东并重分配首屏区块。本次授权覆盖前一轮保留搜索/卡片原尺寸的限制；底部导航、玻璃、全局动效仍保留。

- 固定搜索压至 44 dp；频道用文字与选中短线，右侧固定更多。
- 首屏顺序继续为活动图、新品推荐、双列商品流；活动图 108 dp，新品为紧凑横滑卡，普通商品首屏可见。
- 两列瀑布流按卡片实际高度独立向下排布，左右各 8 dp、列/行间距 8 dp、12 dp 圆角。首页、一级分类和搜索使用同一商品卡。
- 商品主体等比适配显示区域；仅对背景一致的商品图识别安全留白，不修改原始素材。复杂照片保留整体，细长物体不横向拉伸。分类也使用主体适配。
- 明确标题、真实分类、新品标签、价格、信用点单位与加购入口；不新增虚假销量、折扣或评价。
- 新品保持横滑，移除占首屏过大的 405 dp 海报。保留全量标签搜索及服务端分页。
- 独立包仍是 `com.deuterium.app.shopdemo`，更新为 `1.1-demo` / 2；无联网权限、内置演示数据，正式服务和数据库不改。

验收：安装真实演示 APK 检查首屏、分类、瀑布流、标签搜索、加购与浅深色；验证分页、主体裁切边界和包名/权限。正式发布前另行同步后台商品预览，本轮不发布正式 App/Web/Go。
