# 管理员永久注销账号

2026-09-12。用户确认在管理工作台“账号与权限”新增“永久注销”：输入当前登录工作台的管理员密码进行二次确认，成功后执行账号及关联展示清理。不是输入目标用户密码，不在对话里收集密码。本轮实现和本机验收后，用户已授权合并、部署和推送；发布 App 2.0.13（21300）/Web 2.0.15 与配套 Go，不自动注销线上旧号。

## 确认边界

- 仅当前有效的 `platform.admin` 会话可操作；密码在服务端验证，持久限次并复用现有密码算法/哈希并发上限。提交事务再次核对管理员权限、会话、密码摘要和目标版本，禁止注销自己，保留有效管理员。
- 密码不进入日志、审计、数据库请求记录、幂等指纹或前端持久存储。失败/关闭弹窗清空输入；未知结果可用相同请求键、重新验证管理员密码查询并完成原请求。
- 注销为永久终态：移除登录别名、权限、会话、资料、关注关系、相关私聊会话及公开消息，删除个人市场商品及展示绑定。旧主页、搜索、私聊/转账目标和商品详情不能继续访问。
- 保留匿名账号占位以维护交易外键；清除游戏名、QQ、密码，释放原游戏 UUID 的注册绑定。新注册获得新的账号及玩家引用，不继承旧会话、联系人或商品。
- 订单、账单和已完成的争议证据保留。对外结构化账号资料统一显示“已注销用户”，历史财务快照的原始摘要保持可审计。撤销的私聊/公开消息引用不再返回原文。其他用户自行撰写的非结构化文本、外部截图不属于可保证撤回的数据。
- 有未完成订单/委托、退款/平台介入、未知转账时阻止注销。持有商店所有权时先完成归属处理；平台公共分类等管理资源不随创建者注销而清空。
- 注销与账户相关写入通过数据库生命周期门控互斥；常规写入持共享锁并检查账号状态，注销持独占锁。避免并发发消息、挂单或付款在清理后重新写入。
- App 拉取不含旧姓名/QQ的注销引用增量，清理联系人、关注、主页、商品、消息引用及关联缓存；延迟返回的旧数据不能重新加入。离线/旧版客户端需在更新并联网后完成清理。
- 图片移除当前资料/商品绑定并阻止旧资料访问；仍属于他人订单凭据或其他有效业务的图片沿用现有保留/生命周期规则。

## 验收

真实隔离数据库测试管理员自身密码/目标密码隔离、错误密码限次、非管理员/跨站拒绝、会话撤销和改密竞态、终态不可恢复、重复与未知结果重试、挂单/私聊/付款并发、交易阻止条件、联系人/主页/商品/引用清理、历史账单匿名及重新注册隔离。Web 验证确认表单、空密码/错误/等待/取消；Android 验证注销同步、离线缓存、旧请求返回、正在打开的资料/会话和其他联系人保留。不得使用真实账号注销作为测试。

新增迁移仅建立注销记录/门控及状态索引，不删除旧数据。未来部署前备份数据库，先后端/Web再App；回退不能重新激活已注销账号，旧客户端不会具备自动缓存清理能力。
