# 商城导航与游戏邮件标题候选

2026-10-08；基线 `5d7523d`（App 2.0.19 / Web 2.0.28），分支 `xiwanzi/shop-navigation`。本轮为本机候选，不推送、不部署，不更改生产目录及历史邮件。

- 默认游戏邮件标题统一“官方商城订单”，单品自定义标题保留；多商品合单使用同一短标题。订单号及已成交快照保持原有身份关联，桥接、Mail 模组不改。后台预览同步。
- App 商城移除大标题，固定搜索与一级分类（首页、可横滑分类、固定更多），顶部小留白可点回列表顶部。其他一级页面折叠交互不变。
- 首页依次展示已配置活动横图、真实带“新品推荐”标记的横向大卡片、分页双列商品流。没有配置时不制造活动或自动标记商品。
- 分类页展示二级分类图标与双列商品流；最多 15 格，超过时使用 14 个子分类加更多。详细分类页左侧选择一级分类、右侧子分类。点子分类或推荐查看更多进入独立双列搜索结果页。
- 商品搜索按提交关键词查询全部服务端目录，支持继续分页、失败重试及返回浏览位置。推荐查看更多用精确 badge 过滤，普通搜索也支持标签。
- 分类新增可选 `parentCategoryId`，仅允许同店有效一级分类，两层结构；旧记录兼容，移动分类保留 ID 与商品引用。父分类列表包含子分类商品，搜索父分类名覆盖其子分类。用户已确认一级分类为家具家居、灯具照明、绿植庭院、建筑建材、装饰摆件、其他。跨店同名一级分类合并展示并使用 `categoryGroup` 查询。
- 复用店铺首页 `BANNER` section、商品 `badges` 和既有图片权限。新增公开商品 `badge` 查询参数，游标绑定 badge；首页响应附 `banners` 的已授权图片。无需数据库迁移。

验证：Go 标题与分类/标签/图片鉴权用例、Android 分页和页面导航、浅深色及固定顶栏、后台构建。生产数据不用于购买测试；模拟器不代表真机触感。新布局完整体验需候选 Go 与配置共同接入。
