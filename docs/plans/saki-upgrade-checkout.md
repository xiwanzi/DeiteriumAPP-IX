# Saki 套餐升级与原生购买确认

2026-09-10，接续已发布 2.0.6；本文件记录本轮用户确认的边界，完成前不代表上线。

- 聊天输入框上方的套餐入口仅在已加载的新空会话出现，发送或恢复中的消息同样隐藏入口；头像菜单始终保留。
- 最新用户决定：恢复本轮第一版的圆角浮层、白色信息卡和蓝色确认购买按钮；撤销随后试做的紧凑 iOS 复刻布局。用户页面不展示任何计算公式或向上取整规则，只显示最终金额、升级补款与有效期不变。直接点击确认购买。确认与既有付款动画共用一个浮层；保留模拟识别期间提交、真实成功后打勾的时序。
- 升级费用 =（目标套餐现价 − 当前权益购买时的套餐标价）× 剩余天数 / 15。用户明确选择剩余天数向上取整，最终金额四舍五入到 0.01 信用点。升级严格保留原到期时间；同套餐续购沿用延长有效期行为。不支持降级、主动退款。
- 套餐等级沿用后台套餐排序；只有更高等级且价格差为正可补款升级。低于单笔最小金额的计算结果不发起付款。后台改价不会修改已购权益的价格快照。
- 后端生成短期有效的购买报价，绑定账号、套餐版本、当前权益与原到期时间；付款金额由报价决定。旧客户端普通购买/同套餐续费保持兼容，跨套餐升级必须先报价。已受理的付款持续使用原请求恢复；未知结果不重新扣款。
- 复用现有订单、资金预留/结算、失败补偿与报价存储；升级订单保存计算依据。不开启生产购买开关，不修改玩家业务记录或游戏插件。

验收：向上取整边界、金额舍入、到期不延长、连续升级、降级拒绝、报价过期/变更/账号隔离、重复及并发请求、结算未知与补偿恢复；Android 浅深色、空会话/有消息、确认到动画、动效关闭与旋转恢复；Web 同步使用后端报价。
