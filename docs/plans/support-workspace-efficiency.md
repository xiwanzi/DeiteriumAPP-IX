# 工单工作区效率调整

2026-10-04，用户要求以高效处理工单为第一目标。基于已上线 Web 2.0.21 和现有邮件工单接口，本轮调整管理网页；验收发现中文搜索的字符集冲突，一并修复后端查询。不改变邮件模板、邮箱配置、权限和工单存储结构。

- 工单页使用完整可用宽高，默认把全站导航收为图标栏；提供展开入口，离开工单页恢复原布局。
- 用紧凑状态筛选替换大标题及统计卡片；待处理优先，搜索可直接输入，筛选可以清空。
- 列表、对话分别滚动，回复框保持在视口内；用户资料可按需展开，在小屏使用浮层。
- 负责人、状态、解决和上一条/下一条置于对话顶部；回复操作明确表明发送后的状态，支持成功发送后进入下一条。
- 每张工单的邮件回复与内部备注草稿分开保留；失败不清空、不前进，重复请求沿用请求 ID，版本冲突先刷新。
- 验收使用隔离数据库与合成邮件，不向真实用户发送测试信息；检查 1920、1440、1366、1024、768、390、320 宽度、浅深色和实际处理流程。
