## 迁移与发布

旧库只读导出 `app_users` 的身份、状态和 PHC 密码哈希；新库先空库试导。导入预检覆盖重复 UUID、跨名称/QQ 别名冲突、非法哈希参数、禁用状态、重复批次。全部通过后一个事务写入。日志仅输出计数与非敏感错误，不输出密码哈希或用户清单。

首次切换需要旧账号写入冻结窗口、最终增量导出、数量与身份核对、余额来源核对、用户重新登录。未迁移的旧账单可通过只读历史归档保留；不能把只迁移账号描述为业务数据全量迁移。

Linux 最终主机、正式 API/ID/网页域名、OSS 配置和生产新库尚未指定；准备配置模板和部署包即可，不猜测地址自动上线。生产插件替换、库切换和重启另按明确授权执行。
