# 获取验证码时校验正版 ID

2026-10-05 用户确认：正版 ID 校验前移到获取注册验证码；点击即开始 60 秒倒计时，表单继续可用，后台查询。ID 不存在则提示错误、不发邮件并恢复获取按钮；成功才排队验证码邮件，最终注册复用结果。相同 ID 换邮箱使用 10 分钟成功缓存，改变 ID 重新查询。失败结果不缓存、不绕过服务端限流。

后端在发码请求的限流与邮件通道检查后查官方档案，校验成功标志绑定服务端验证码记录。新增 034 迁移记录成功缓存与标志；旧未标记验证码仍在最终提交时安全校验一次。存在性检查与游戏持有证明、UUID 绑定及白名单继续分开。倒计时以本次请求开始为基准；实际发码失败立即解除客户端倒计时，服务端既有安全限额保留。
