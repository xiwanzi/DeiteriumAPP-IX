# 注册提交时校验正版 ID

2026-10-05，用户要求所有注册入口在点击注册的最后一步查询正版 ID；不存在时提示并拒绝本次注册。

官网、客服中心和社区调用 `POST /api/v1/web/register`，App 调用 `POST /api/v1/account/register`，两者均由后端 `registerEmail` 创建账号。在邮箱验证码检查成功之后、密码计算及账号写入之前，复用白名单申请的 Minecraft 官方玩家档案查询。查询对象为服务端验证码记录中绑定的 `gameId`，不接受客户端另传 ID 绕过。

- ID 不符合 Minecraft Java 玩家名格式或官方返回不存在：400 `MINECRAFT_PLAYER_NOT_FOUND`，提示核对正版账号 ID。
- 官方接口超时、限流、异常响应：503 `MINECRAFT_LOOKUP_UNAVAILABLE`，提示稍后重试；不按不存在处理，也不放行。
- 失败时不创建账号、别名或会话，不消耗邮箱验证码；原有失效时间、错误次数与并发单次消费规则保留。
- 查询只确认玩家档案存在，不证明操作者持有该账号，不设置游戏验证完成、不绑定 UUID、不授予白名单。已有账号及资产保持。
- 保留验证码发送时机、原注册 UI 与各端现有后端错误提示。无需客户端升版或数据库迁移。

验收覆盖两个注册接口、不存在与格式错误、服务不可用及同码重试、错误验证码不触发查询、注册成功后的未验证状态与单次消费。网络响应测试覆盖 200、204/404、429/5xx、异常档案与取消。使用本机隔离数据库和模拟查询，不发送真实邮件、不创建生产账号。

当前为本机实现任务，推送及生产 Go 替换依本轮发布授权执行。
