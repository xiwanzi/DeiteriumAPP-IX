# 管理与流水体验增量

2026-09-09，基于已发布 2.0.3，工作分支 `feat/admin-ledger-v204`。本页记录本轮用户明确要求及实现边界；发布状态仍以部署记录为准。

## 范围

- 公告管理增加永久删除，删除公告正文、草稿、已发布版本和对应通知，解除图片业务引用；保留不含正文的删除审计和幂等回执。界面明确不可恢复并二次确认，服务端校验权限与版本。
- 增加 SMTP 配置及接收邮箱页面。平台介入新申请和需要管理员处理的后续状态通过持久通知队列发送，失败退避重试；配置仅平台管理员可改，密码不回传、不进入审计。配置缺失时保留待发送状态，页面显示送达状态。
- 管理审计增加全服资金流水和玩家查询，查看玩家的全部买入/卖出订单、市场商品及其管理的官方商品，保留原操作审计。每个请求检查管理权限，不受玩家的个人隐藏偏好影响。
- 商品编辑保持现有视觉，简化常用发布路径，固定明确的保存/发布操作，表单有未保存内容时防止遮罩、导航、关闭或刷新导致误退出。
- App 统一删除操作的红色语义及样式；最近流水和个人订单/商品/委托按真实时间倒序；修复主题切换闪屏。
- 游戏内消费、收入、转账与 App 业务统一读取 XConomy 已提交账本。游戏内原生操作显示“游戏内收入/游戏内支出”；不会通过余额差推测、补写虚拟交易或把资金执行两次。

## 数据与权限

资金权威继续为 XConomy：新增只读分页 API → Core 的受限只读命令 → Go 鉴权查询 → App/Web。个人查询强制绑定会话 UUID；全服查询要求 `audit.read` 或 `platform.admin`。账本按时间及序号倒序，分页固定筛选与时间范围，支持历史数据，禁止读取凭据或修改经济余额。系统托管账户与玩家记录明确区分。

新资金查询协议同步 Core/XConomy 版本及文档；不复制第二份资金权威。SMTP 发送在业务提交之后，由持久队列处理，发送失败不回滚介入状态。邮件仅含案件编号、状态和站内入口，不发送聊天证据正文。

## 验收与交付

使用本机隔离 MariaDB 验证删除的版本竞争/幂等/权限、通知入队与重试、审计分页与账号隔离，以及原生经济收支/转账和商城预付退款的账本一致性。运行 Go 相关集成测试与 race、Web 构建及浏览器交互、Android 单测/Lint/模拟器浅深色与排序验证、Core/XConomy Maven 测试和打包。

新增数据库迁移只增不改既有迁移。上线前备份配置、业务数据库和原程序；回退仅切旧程序/配置，不用旧数据库覆盖新增业务。本轮先完成代码、可审阅差异和可安装产物；真实 SMTP 配置与实际发布按最终交付及用户授权执行，模拟器不替代真机手感。
