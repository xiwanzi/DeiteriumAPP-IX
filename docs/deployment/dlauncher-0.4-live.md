## 上线内容

启动器管理支持安装基线、内容草稿/发布、图标/背景/视频、宣传图和公告配图。原生 McPatch 用于上传及打包；“同步到 OSS”调用原生上传逻辑，核对完整性后发布可用更新索引。登录信息只向平台管理员提供，OSS 和管理端秘密由服务器环境提供。

McPatch 管理端为 v2.0.5 加本轮适配：8 MiB S3 分片完整读取、同步错误正确返回、索引最后上传、公开文件目录限制。原生页面适配 `/mcpatch/`。桌面 Java 更新核心 v0.0.12 改为无界面事件输出并具备文件恢复，包格式不变。

基线 `2026.09.12-baseline` 已发布，8,229 个文件，TAR 1,310,852,096 字节。Minecraft 1.21.1 / NeoForge 21.1.248 的本体、依赖与 assets 走官方/镜像；OSS 提供服务器资源。桌面端补齐基线后自动检查最新版本。
