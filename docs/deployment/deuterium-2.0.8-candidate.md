# Deuterium 2.0.8 候选交付

2026-09-10。**实现与本机验证已完成，尚未合并发布到生产。** 当前已发布版本仍为 [2.0.7](deuterium-2.0.7-live.md)。

## 变更

App 2.0.8（20800）默认使用已选定的白底黑色弧线 D，同时内置用户确认的“911双子节”周年活动图标。两种图标可由平台管理员在网页“应用图标”页预览、发布和切回默认。在线 App 接收配置提示；启动、回到前台与前台定时读取覆盖断线情况。图标切换不要求重新安装，新图案仍需随 APK 预置。

为兼容桌面升级，默认 alias 延续旧 `.MainActivity` 名称；真实 Activity 始终保留，通知使用稳定的真实入口。关于页预览显示当前选择。网页登录、导航和 favicon 使用新版默认 D；App 的登录 / 开屏版本徽标继续沿用原设计。

后台保存使用管理员鉴权、CSRF、事务内权限复核、请求幂等、版本检查与审计；网页不把配置保存成功显示为所有设备已同步。新增数据库迁移 `022_launcher_icons.sql`，仅创建图标配置表并初始化普通图标。

## 发布顺序

按本轮发布授权执行。先做数据库及现有配置 / 程序 / 网页 / 更新清单备份，再部署兼容旧客户端的 Go 并执行新增迁移，确认公开图标配置为 `default`；随后更新网页，最后发布同签名 APK 和更新清单。不要把后台切至活动图标作为发布验收的默认生产操作。

发布后检查：服务 ready，旧 App 获取 20800 / 新 App 不降级；管理员能查看两种内置图标；普通账号不能修改；公共默认配置正常；真实业务数据和游戏服务保持原状态。

## 回退

外观回退通过后台发布更高版本的 `default`。不得降低配置版本或恢复整库覆盖新增业务。撤回分发可恢复旧更新清单和网页，但已安装 20800 不会自动降级；若回退到不支持图标接口的旧 Go，App 会保留最后有效选择，因此应先处理需要的默认图标同步，或保留兼容接口。
