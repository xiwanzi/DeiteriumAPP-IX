# 启动器 0.6.1 / Web 2.0.19 上线

2026-09-13 13:58（UTC+8）上线 Web 2.0.19 与配套 Go；14:07 通过正式管理页发布启动器 0.6.1。源码 `25a2ed8cc1f1` 经 [PR #39](https://github.com/xiwanzi/DeiteriumAPP-IX/pull/39) 合入 main，合并提交 `f8a4d90818ba`。

## 功能

- “启动器 → 启动器版本”独立管理 Windows 程序更新。选择 ZIP 与签名 JSON，直传现有 OSS，后台复核签名、大小和 SHA-256 后发布；采用递增版本、乐观修订和幂等请求。
- 新公开接口 `/api/v1/launcher/application` 提供签名版本信封。桌面启动器检查版本后弹出不可跳过的更新提示，由随包独立更新器完成下载、校验、原地安装和重新启动。
- Web 为 Qt WebEngine 内嵌模式提供紧凑深色样式与黄色强调色，保留完整社区业务。右侧全部区域用于社区，没有额外启动器社区工具栏。
- 程序发布不改变 McPatch 内容草稿、整包资源基线和 OSS 同步记录。Android 保持 2.0.13；本轮没有发送账号更新提醒或邮件。

## 后续维护与回退

启动器源码由 [Deuterium-IX/DeLauncher](https://github.com/Deuterium-IX/DeLauncher) 独立维护。后台发布时同时选择构建产生的 `update.zip` 与 `release.json`；不要使用 `bootstrap.zip`。0.5.x 玩家需要先手动覆盖升级一次，因为旧程序没有自更新代码。

若配套 Web/Go 需要回退，可切换至保留的 `mail-appearance-f87d15598a88` 与 `web-2.0.18-57878e526653/dist`，但必须先安排程序版本接口继续可用，否则已接入强制检查的启动器将无法进入主界面。新增发布表可保留；不得恢复整库覆盖上线后业务数据。

已发布 Windows 版本不倒退；运行逻辑问题通过更高版本修复发布。独立更新器的自动恢复针对安装中断和文件替换失败，不等于所有运行错误自动降级。
