## 已发布行为

- 完整聊天输入框和 T 快捷聊天支持 Ctrl+V 图片粘贴，进入现有图片预览；点击“发送”才上传并投递。普通文本/网址继续走文字粘贴，不将网址自动下载成图片。
- Windows 使用游戏现有 JNA 读取 PNG、DIB/DIBV5 截图或单个复制图片文件，兼容 Minecraft 的 AWT headless 模式。压缩和 PNG 编码在图片工作队列完成；保留 20 MiB 文件和 4000 万像素限制。非 Windows 无界面环境暂不支持图片剪贴板。
- 准备期间重复粘贴不会重复排队；切换会话、频道或关闭原页面后丢弃迟到预览。预览取消不发送，Esc 返回聊天并保留文字草稿。
- 用户选定 ModernChat 实际引用的 `l1ghtmod:player_chat` 原音，改名为 `message_pop.ogg`，接入 `ui.receive`。使用原 OGG 字节而非重新编码试听 WAV；时长约 0.264 秒，保留既有提示音开关、音量及自身/历史消息过滤。
- HUD/T 公屏在玩家名后显示当前铭牌，保留渐变和权威佩戴同步，服务器名加方括号；宽度不足时沿用头部字段防重叠策略。
- HUD/T 的实时列表排除载入的历史，完整私聊仍保留历史与失败重试查询。
- 铭牌页点击时重新计算当前屏幕坐标的命中目标，修复快速移鼠后沿用上一帧目标的路径。
