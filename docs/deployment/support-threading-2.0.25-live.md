## 行为与根因

QQ / Android 邮件回复缺少 References 和 In-Reply-To，原实现只查引用头与旧主题编号，导致管理员主动邮件的回复另建工单。现在正文中的「工单编号」配合同一玩家邮箱可接续原工单，玩家回复转为待处理，保留最早管理员邮件与全部后续历史，不另发新建回执。多个不同有效编号进入人工核对，异邮箱无法归并。

全部列表与计数默认排除已关闭；搜索可找关闭工单及合并前编号。排序依次为待处理、处理中、等玩家回复、已解决、已关闭；同状态按优先级和更新时间。输入搜索会切换全部状态。
