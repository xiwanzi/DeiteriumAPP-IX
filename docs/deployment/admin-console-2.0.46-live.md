## 发布内容

- **管理后台导航重构**：将原 18 项平铺侧边栏重组为 5 大可折叠业务域（客服与风控 / 商城与运营 / 玩家与游戏 / 客户端与 AI / 系统与审计），新增「工作台总览」（含实时待办 KPI、常用固定入口、最近访问与业务域导航卡）、全后台可收起极简图标栏，以及 `Ctrl+K` / `/` 全局命令面板（支持中文、英文与拼音首字母直达）。仅拥有 `support.manage` 的账号仍直接进入工单工作台。
- **高频子页专项提效**：
  - 商店管理（`/merchant`）：升级为 5 标签页内工作区（商品目录 / 分类与品牌 / 交付模板 / 商店订单 / 店铺与首页），取消多层弹窗套娃；新增可视化两级分类树、批量加载更多商品、行内「更多」菜单及一键复制商品草稿。

  - 图片审核：支持勾选批量删除、按风险维度/高危分数筛选，详情大图支持 `← / →` 键盘连续翻图。
  - 账号与权限 / 白名单 / 头衔 / Core / 玩家键位 / 小祥知识库 / 启动器 / 邮件 / 优惠券 / 审计：收口表格多按钮为分组菜单、白名单双选审批卡与常用拒绝原因标签、头衔可视化渐变配色生成器与双背景预览、Core 状态灯胶囊与物品库搜索、键位按下键盘直接录入、小祥知识库折叠搜索、启动器单行同步条与新闻调序、邮件状态筛选与优惠券复制。
- 样式严格收口于 `.management-shell` 与 `.adm-*`，玩家端前台页面与 Go 后端接口零改动。
