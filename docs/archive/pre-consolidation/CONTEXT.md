## 产品结构

| 原生 App 一级入口 | 内容 |
| --- | --- |
| 商城 | 官方商品、购物袋、报价、付款、订单与游戏内邮箱交付 |
| 市场 | 玩家物品/建筑服务、发布、上下架、买入/卖出、担保与退款 |
| 信息 | 公共聊天、私聊、AI、公告与委托大厅入口 |
| 我的 | 资料、账号、钱包/账单/转账、订单、外观、通知和更新 |

网页采用适合桌面与移动浏览器的导航，另有商店和平台管理入口；不照搬原生 App 底栏。主题继续使用系统/浅色/深色；柔光玻璃分导航和浮层开关，保留“灵动视效”“动态追光”命名。支付的扫脸、蓝色圆环与确认勾是本地视觉，不是真实 Face ID、Apple Pay 或 Mastercard 服务，也不采集人脸。

## 工程与职责

- **Android**：Kotlin + Jetpack Compose，当前模块 `android-app/ui-lab`，包名 `com.deuterium.app.uilab`，Android 8.0+；延用原测试签名支持覆盖安装。
- **网页**：同域 `/api/v1`，HttpOnly Cookie 与内存 CSRF；发布静态 `dist`，由 Nginx 提供 HTTPS 和 API/WebSocket 代理。
- **当前业务后端**：`backend-next`，Go 标准 HTTP、显式 SQL、MySQL/MariaDB、校验迁移摘要，部署于 Linux。采用[ADR 0009](../../adr/0009-deuterium-backend-core.md)；旧 Ktor/Exposed/Flyway 仍作迁移和协议参考，不是当前已发布服务的运行栈。
- **游戏侧**：Java 21、Youer/Minecraft 1.21.1；Core 通过 WSS 主动连接后端。Core 管理物品版本、桥接日志和受控经济调用；独立 Mail 管理邮件、领取、撤回；Sync 提供玩家状态与保存证明。邮箱没有并入 Core。
- **数据边界**：App/Web → 后端 API → Core → 受控 XConomy/独立 Mail/Sync。客户端不连接数据库、不持有节点或存储凭据，不自行修改余额、决定结算或重发未知领取。

## 领域词典与已确认规则

| 术语 | 含义和边界 |
| --- | --- |
| Deuterium ID | 稳定第一方账号主体 userId；原账号已迁移，名称与 QQ 是登录/展示标识，不替代主体或游戏 UUID |
| Minecraft 身份 | 可信游戏节点解析的 UUID；资产和收件人以该绑定为准，不能由客户端自报或按相似名称合并 |
| 信用点 | XConomy/Vault 是经济权威；后端编排受控操作，不复制一套可自行改写的游戏余额 |
| DIMA / DaoYu | 已由 Amiya 控制台初始化的官方收款/冻结资金系统专户；初始各 0.00、hidden=1，不创建 App/QQ/密码身份 |
| 成交快照 | 冻结商品、价格、数量、模板版本、摘要、收件人和领取名单；后续改稿、改价、模板编辑不改变旧订单 |
| 未知结果 | 查询原 operationId 或原请求键；不换键重复扣款，不把 UNKNOWN 或普通 NOT_FOUND 当成失败/退款证明 |
| 建筑工期 | 从开始施工计时，包含验收预留；完成不重新开始总工期，未完成工程不自动结算 |
| 委托 | 发布者预付后公开，其他玩家互斥接取；提交完成后有独立 72 小时验收期 |
| 平台介入 | 当事人主动提交相关证据与消息引用；管理员按权限查看冻结资料、处理案件，不默认遍历无关私聊 |
| 全量/资源更新 | 全量为经哈希、包名、签名和版本校验的 APK；资源只允许图片、文案、配置，不运行代码 |

AI 当前规则是 **DeepSeek V4 Flash、按需联网搜索、免费 20 次/24 小时、平台管理员免次数额度**。其余计划标价 `9999999.00` 且禁止购买；供应商 Key 只存在于服务端受限配置。来源与正文链接分别标记，不伪称链接已经核验。

权限以每次服务端鉴权为准，普通账号、店铺成员和平台管理员分开；旧账号、QQ、游戏 OP 不自动变为管理员。当前未提供账号封禁的完整操作规则，也未宣称实现完整第三方 OIDC Provider。
