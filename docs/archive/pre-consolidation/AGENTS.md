## 技术与产品边界

- Android 已采用 Kotlin + Jetpack Compose。Material 3 可作基础设施，新版不采用其默认控件外观；使用 iOS / HyperOS 视觉方向，见 [ADR 0008](../../adr/0008-current-product-and-visual-baseline.md)。
- 主题只有系统/浅色/深色，不恢复动态取色和彩色主题。“柔光玻璃”分导航栏和浮层两个开关，保留材质参数；使用“灵动视效”“动态追光”新命名。
- 第 07 版所有付款模拟扫脸后衔接蓝色圆环与确认勾，不是真实 Face ID、Apple Pay 或 Mastercard 服务，不采集人脸。
- 后端已有 Kotlin/JVM + Ktor + MySQL/MariaDB + Exposed + Flyway；插件使用 Java 17 + Bukkit/Spigot，兼容 Mohist 1.20.1。
- 保持 Android → 后端 API → 插件桥 → 服务器边界。正式身份以服务器解析 UUID 为权威，游戏内 ID/QQ 是输入、展示或登录标识。
- 正式信用点经济使用 XConomy/Vault 路线。App 不直连数据库、不持有服务器凭据、不直接改经济数据。
- 商城、市场担保、委托预付、跨设备私聊/通知及新更新流程必须按新契约接入，不能把本机示例或旧转账接口当成已支持这些能力。

## 实施与验证

先读相邻约定，沿用现有实现，不做无关重构。已有明确规则的小改动直接做；新增身份、资金、权限、协议或状态机时，先记录已确认边界再实现。已有授权无需重复询问；关键缺失无法从指定任务核实再澄清。

敏感流程必须考虑鉴权、身份绑定、幂等、并发、结果未知及恢复。按模块验证：

- 账号：验证码、注册登录、改密、失败限次、会话撤销、资料权限。
- 钱包交易：余额/库存不足、重复提交、冻结/结算/退款互斥、一次退款机会、期限暂停恢复、重启补算。
- 委托：预付、互斥接取、完成确认、72 小时验收、逾期和退款。
- 聊天通知：收发、重连去重、引用、提及/特别关心、权限拒绝、接收人隔离。
- 插件桥：离线、超时、鉴权失败和受控经济操作失败。
- 更新：真实进度、完整性/签名/版本、资源路径和大小、失败回滚；资源包不运行代码。
- UI：浅深色、搜索/键盘/返回、渐变模糊、动效关闭、覆盖安装和持久化；模拟器不替代真机手感验收。

纯文档整理验证链接、矛盾与差异即可，不重跑全部业务构建。不把历史测试写成本次新验证。
