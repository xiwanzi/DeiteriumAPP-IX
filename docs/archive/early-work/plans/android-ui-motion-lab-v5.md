# 体验版 05：视觉统一与订单闭环

> 已归档（2026-09-08）：保留早期实施与设计记录，不作为当前任务指令。当前需求见 [新版产品基线](../../../prd/deuterium-current.md)，归档目录见 [历史索引](../../README.md)。

## 用户确认与边界

根据 2026-09-07 最新要求，继续只修改原生 Android `ui-lab` 体验版及文档，版本升级为 `0.5.0-ui-lab (5)`。去掉 Material Design 的控件外观、动态取色及彩色主题选择，保留统一的 iOS / HyperOS 方向与浅色、深色适配。正式 App、后端、插件及生产资金不参与本轮。

用户已经确认官方商品通过**游戏内邮箱**交付。市场采用平台担保：买家付款后资金冻结，卖家发货后买家才能确认收货，二次确认后才结算给卖家。以下实现均使用本机体验状态，不作为真实经济系统的新接口或架构决策。

## 视觉与滚动

- 阅读 Apple HIG 的 Materials、Search fields、Toolbars 和 Adopting Liquid Glass；将玻璃用于导航和浮层，用分组实体表面承载内容，优先保证浅色/深色对比。
- 参考用户提供的两张设置截图，先收起搜索区域，再将大标题上移并切换为居中小标题，只有内容进入顶部工具栏区域时才出现边缘模糊。初始静止页面不模糊正常商品。
- 商城持续提供搜索与购物袋：展开态搜索框，收起态搜索按钮；市场、信息、我的采用同一收起时序。
- 用统一分组列表、蓝色操作、胶囊按钮、细分隔线、定制开关/分段选项/弹层取代 MD 风格。主题只支持系统/浅色/深色。
- 加入购物袋时显示商品飞入购物袋、数量更新与完成反馈。头像进入圆形裁切预览，可缩放与移动后保存实际裁切图。
- 支付保留原始声音，按用户要求将后半段合并圆衔接为勾并停留；明确这是本版定制结尾，不再描述成整段原版未修改。

## 商城、市场与订单

- 官方商城：多组商品图片、介绍、包装内容、交付方式与预计送达时间；结算后创建独立订单并进入详情。订单为未领取/已领取，配送记录显示已发送游戏内邮箱；未领取可退款，领取后禁用退款。
- 市场：玩家商品详情复用商城的标题、副标题、图片、详细内容结构，另有卖家、库存、交付选项。购买必须选择送货上门或约定自取，并填写相应地点信息。
- 提供发布商品表单：名称、简介、图片、详细说明、分类、价格、库存、交付方式、卖家 QQ 和交付地点等必要信息，校验后加入本机市场。
- 我的订单成为独立页面，区分商城订单/市场订单。市场支持查看买入和卖出订单；从历史条目进入独立详情。
- 订单详情包含商家/卖家、商品快照、订单号、创建/发货/完成时间、交付信息、支付金额、状态进度与资金状态；市场提供 QQ 复制、客户端私聊、确认收货和退款入口。
- 市场未发货不能确认收货；已发货确认需二次确认，确认后关闭退款入口并结算冻结金额。测试控制入口允许推进模拟卖家发货、领取和退款处理，普通操作文案保持产品风格。

## 数据与失败处理

订单使用创建时的商品快照，避免后续编辑影响历史。交易入口带本机幂等标识，快速连点及配置切换不能重复扣款/退款/结算。冻结、退款、领取、确认收货统一校验状态，已退款或退款处理中不能发货/确认/领取；余额不足和库存不足不创建付费订单。

用户已确认市场退款规则为“未发货立即退款；已发货提交申请，等待卖家同意”。不同意或取消申请后恢复原履约状态。退款通过后返还买家余额、解除平台冻结；已完成订单不退款。

## 验收

1. 展开、收搜索、收标题、滚动模糊四个阶段录屏核验，商品静止时清晰，反向滚动可恢复，搜索和购物袋始终可达。
2. 浅色/深色、分段选项、开关、弹层、表单与信息页一致；动态取色和颜色主题入口完全移除。
3. 商城下单→订单详情→领取或退款；市场下单→冻结→发货→二次确认→结算，以及未发货退款/已发货申请流程。
4. 无效必填项、余额/库存不足、重复操作、禁止跨状态操作与配置切换验证；不涉及真实后台交易。
5. 头像缩放/平移裁切及保存后重启显示；购物袋动效、支付勾结尾和完整声音；APK 版本/签名/权限、构建、Lint 与主要 UI 流程检查。

## 完成记录与设计依据

- 对照 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Search fields](https://developer.apple.com/design/human-interface-guidelines/search-fields)、[Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) 与 [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) 阅读官方文档。主要采用内容/导航分层、根据背景维持可读性、明确搜索范围和滚动边缘遮罩的原则；截图中的先收搜索再收标题时序是本版自定义 Android 实现。
- 原生 Compose 中自定义分组列表、按钮、开关、分段控件、滑块、日历、确认框与底部弹层；Material3 只继续提供文本/表面等基础设施及语义色值，不采用其默认交互控件外观。动态取色与颜色选择入口和逻辑已移除。
- 搜索区先消费 68 dp 滚动，大标题随后消费 60 dp。模糊边缘限制在 48 dp 紧凑工具栏范围，初始展开不模糊商品；四个根页面保留各自的展开/搜索状态。
- 官方商城新增 12 张 Apple 官方详情图，按需采样解码，防止原始大图占用过多内存；来源见 `ui-lab-v5-assets.json`。
- 市场和官方订单采用不可变商品快照、幂等下单键和受控状态迁移。市场冻结、发货、确认结算、未发货立即退、发货后退款申请/同意/拒绝/撤回均已实现。订单历史为当前体验进程中的记录。
- 头像提供圆形可视范围、拖动、双指缩放及缩放滑块，保存真实 640×640 裁切图片；重启后头像保留。
- 支付使用 SDK 前段动画并在合并圆后衔接自定义勾，完整原音效及其 290 ms 延迟保留；完成后自动进入订单详情。此结尾是定制，不再宣称整段未修改。

验证：15 项订单单元测试全部通过，构建与 Lint 完成（0 errors / 11 warnings）。模拟器验证展开/收搜索/收标题、浅深色、商品图库、加购动效、支付勾、官方订单退款、市场必选交付、冻结→发货→二次确认→结算、发布商品与卖家接单、发货后退款、中文日期范围、聊天输入和头像实际裁切保存。发货后退款中禁止确认收货，卖家同意后余额从 11,800.00 恢复到 12,480.00。

11 项 Lint 提示包括已有工具/SDK/图标配置提示和 Android 8 兼容分支使用系统 ExifInterface 的建议；无阻断错误。没有新增网络、图库全量读取或后台保活权限。真实平台担保、服务器邮箱与通知推送仍需后端/插件接入，本轮没有修改正式 App、后端和插件。
