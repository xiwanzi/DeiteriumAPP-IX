# Android 视觉与动效空壳体验版

> 已归档（2026-09-08）：保留早期实施与设计记录，不作为当前任务指令。当前需求见 [新版产品基线](../../../prd/deuterium-current.md)，归档目录见 [历史索引](../../README.md)。

## 目标与基线

用户授权制作可安装的空壳测试 App，用于评估动画流畅度、动效设计与界面美观度。基线为公开源码 `bf81890` 中的 Android `1.0.5 (7)` 正常版，使用当前客服小祥头像；不采用 `26063` 的 TG-like Canary 页面。

遵循 ADR 0001：Kotlin、Jetpack Compose、Material 3。沿用当前工程 SDK、Kotlin、Compose 及构建工具版本；不新增第三方 UI 框架。

## 涉及范围

- Android：新增独立 `:ui-lab` 应用模块，包名 `com.deuterium.app.uilab`，显示名“Deuterium 体验版”，版本 `0.1.0-ui-lab (1)`。
- 文档：本计划与交付说明。
- 正式 App、后端、插件、接口契约：不修改。

## 页面与交互

- 钱包：翡翠色余额主卡、收入/支出摘要、分组流水、余额隐藏、模拟刷新、转账弹层和成功反馈。
- 聊天：清晰的会话标题、在线玩家弹层、头像与消息分组、输入栏、发送和模拟回复、消息复制。
- 小祥：复用现有头像，欢迎页、示例问题、逐段模拟输出、停止生成与新建对话。
- 我的：个人信息、浅色/深色/跟随系统、动效开关、体验说明和重置演示数据。

视觉保留正常版的翡翠色、圆角卡片和原生控件，收敛重复标题，建立统一的间距、文字层级和语义颜色。页面使用短距离位移与淡入淡出；按钮使用轻量按压反馈；列表只对新增项目做入场动画；动效开关关闭后停用自定义持续动画，系统动画缩放继续由 Compose 处理。

## 数据流与安全边界

页面动作只修改应用内模拟状态，不建立网络连接。Manifest 不申请 INTERNET 权限；不接入真实账号、token、余额、转账和聊天。页面直接显示演示标识。正式 App 与测试 App 使用不同包名，可共存。

不定义新周目经济规则、账号迁移或 API。模拟金额、玩家与回答仅为视觉评估样例，不代表新产品决策。

## 失败场景与验收

- 模拟转账校验金额和余额，确认页明确为演示；连续点击时只执行一次。
- 小祥生成过程中可停止，切换页面不丢失会话内容。
- 键盘展开时输入栏保持可见，系统返回优先退出弹层/转账，再回到钱包。
- 四个页签、刷新、复制、模拟转账、模拟消息、主题切换和重置均可操作。
- 独立包可构建，APK 包名、版本、签名和权限经工具核验。
- 执行 Android lint；如有可用设备或模拟器，进行安装、截图与交互检查。流畅度未进行真机测量前不宣称达到特定帧率。

## 实施选择

用户已确认视觉基线及空壳范围。独立模块、独立包名、模拟数据和默认翡翠浅色是本轮可回滚的实现选择，不作为正式产品架构变更。
