# 体验版 02：商城、支付动效、键盘同步与液态玻璃

> 已归档（2026-09-08）：保留早期实施与设计记录，不作为当前任务指令。当前需求见 [新版产品基线](../../../prd/deuterium-current.md)，归档目录见 [历史索引](../../README.md)。

## 已确认目标

用户在体验版 01 上要求：重做转账动画，参考 Mastercard 支付动画的质感；首屏改为假设中的服务器商城 UI，转账移到二级入口；修复聊天输入法开关引起的页面收缩跳动；引入液态玻璃材质。沿用客服小祥头像正常版基线，不采用 TG-like Canary 页面。

本次仍是原生 Compose + Material 3 离线空壳。保留 `com.deuterium.app.uilab` 和 Debug 签名，以 `0.2.0-ui-lab (2)` 更新安装；保留上一版 APK。原 `:app`、后端、插件、生产数据与契约不改动。

## 实现与交互

- 默认底栏：商城、聊天、小祥、我的。我的 → 钱包与转账为二级页；该页再进入模拟转账。商城中的钱包快捷入口也打开同一二级页。
- 商城：主题推荐、分类、商品卡、商品详情、购物袋与本地模拟结算。商品/价格仅用于视觉预览，不形成新周目经济规则。
- 支付：独立、连续的汇聚动画，双轨运动、光环、确认标记绘制和结果收束，使用 Deuterium 翡翠/香槟色，不使用 Mastercard 标志或暗示真实支付接入。转账与商城模拟结算复用支付反馈。
- 输入法：固定标题高度；底栏作为独立覆盖层，不因键盘布尔状态移除布局；输入区只消费一次 IME insets，与系统同步。聊天采用倒序底部锚定，移除键盘高度驱动的延迟 scrollToItem。AI 会话采用相同底部锚定。
- 材质：顶部和浮动导航采样下层真实绘制内容，采用图层模糊、折射、高光边缘与透明染色；商品卡采用同一材质语言。API 33+ 使用 RuntimeShader 折射，API 31–32 使用 blur，旧设备降级为半透明高光表面。提供材质开关，正文不模糊。图层必须保持无循环依赖，不做每帧 Bitmap 截图。

## 数据、安全与失败场景

仍无 INTERNET 权限。模拟结算/转账仅修改内存余额；提交锁避免重复执行，取消、余额不足和重复打开必须可用；支付成功后再更新演示订单/流水。用户离开或停止动效时取消对应任务。

- 同签名覆盖安装，包名/versionCode/versionName/权限核验。
- 冷启动进入商城，四个主 Tab 与二级页系统返回正确。
