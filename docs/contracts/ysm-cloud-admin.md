# 模型 Cloud 管理入口

Web 2.0.35 的模型页继续使用现有管理导航和平台管理员会话。Go 仅允许显式列出的 `/api/v1/admin/ysm/cloud/*` 路由，经过同机私有 Velocity 网关访问 Cloud。普通账号不能调用管理接口；Cloud 管理令牌和 S3 写凭据不进入浏览器。

页面支持模型搜索/分页、发布新版本、撤下/恢复、版本记录和回滚、玩家外观查询、Citizens NPC 的模型/贴图/动作配置、节点及活动审计。NPC 的期望修订与已应用修订分别显示，保存成功不等于游戏端已经显示。

上传为有上限的原始二进制，保留中文模型 ID、SHA-256、期望版本与幂等键。Go 不转发浏览器的 Authorization/Cookie 到 Cloud；管理突变仍要求平台管理员和网页 CSRF。未知执行结果不自动重发或换幂等键。审计 action 使用固定长度分类，目标路径另存，避免长模型 ID 使审计写入失败。

Cloud 连接配置通过私有网关保存；公开响应只返回地址、配置修订和令牌是否已设置。模型对象在 Cloud 解析、验证并发布到 S3 后才推进有效版本。详细游戏模块、节点协议及迁移流程在 DeuteriumYSM 仓库的 `docs/SPARKLE_MIGRATION.md` 维护。

本次没有 App 数据库迁移，不修改账号、订单、委托、库存、聊天、邮件或经济数据。Android 安装包不随这一管理页面更新。
