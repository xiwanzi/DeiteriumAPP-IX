# 玩家键位同步

一个正版游戏 UUID 对应一份键位。Core 从已认证的玩家连接取得 UUID 和进服会话，Go 与当前在线节点、会话核对后签发仅可同步本人键位的凭证。改名沿用原档案，玩家无需先注册 App。只有平台管理员能打开键位工作台。

客户端只同步已注册动作及键盘、鼠标、修饰键、未绑定值。首次建档上传完整键位，换机先读取云端，已有客户端按版本交换变化。玩家在按键设置中保存时记录本地修改，重连补传。客户端保留独立于整合包更新目录的个人基线。首次在本机开启远程协助后，管理员的改动才会应用，玩家可在按键设置撤销最近一次远程调整。

工作台编辑提交动作版本。后端保存目标键并通过现有游戏连接提醒客户端，客户端本地应用、保存并回执后才显示已生效。离线时排队，两端同时改动同一动作时保留本地值和后台目标，供管理员处理。客户端缺少对应模组时，工作台显示该动作当前不可用，装回后沿用个人键位。不同动作可独立修改。

迁移 046 仅新增玩家配置表和动作表。发布前备份数据库，回退程序时可保留两张表用于恢复。Go 与 Core 在握手时协商键位功能，游戏客户端、Core、Go 和管理页面可分步更新。

Core 接到后端握手后立即保存键位同步能力，游戏主线程可用后再通知在线玩家。管理员可用 `dc status` 查看当前节点的键位同步状态。
