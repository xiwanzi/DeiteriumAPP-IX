# 商城目录与优惠预估（App 2.0.20）

2026-10-08，用户授权正式发布。普通价格浅色黑/深色白，优惠价及优惠信息采用已选择的 `#ED6697` 粉色；币值与账务协议不变。

公开商品列表与详情可返回 `offerPreview`：`couponId`、`couponName`、`condition`、`finalPrice`、`saving`、`stack`、`expiresAt`、`asOf`。金额仍为两位小数字符串。没有可额外节省的真实券时省略此对象。

- 身份由当前登录会话确定；只读查询该账号已通过游戏验证、当前生效、符合受众范围且未占用/使用的券。列表响应 `Cache-Control: private, no-store`，不返回受众名单。
- 每页只加载一次可用券；逐商品按一件调用现有 `promotionTotalsV209`，保持范围、门槛、叠加、封顶、舍入和同优惠时到期/ID 排序，与单件结算一致。不新增结算权威，不预占或消耗券。
- 单个商品不能形成可购买报价时不返回预估，不影响其他商品展示。数据库读取错误仍返回正常错误。
- App 校验 `saving = effectivePrice - finalPrice`、有效金额与必要字段；过期后撤下券后价。本人已付款订单消费的券从本机预估缓存移除，返回目录时重新读取。
- 预估不作为下单金额或券选择凭证提交。真实报价/提交继续校验最新商品版本、资格、库存、券状态及并发；单件预估不承诺多件购物袋价格。

分类的可选 `parentCategoryId` 仅允许同店有效一级分类；两层结构，禁止循环及跨店引用。公开 `categoryGroup` 精确匹配跨店同名一级分类及其子类。既有分类 ID、商品引用与成交快照保留。

本轮无数据库 schema 迁移。分类归并通过已授权管理 API 完成，发布前备份原分类；回退配置时不得用整库备份覆盖新业务数据。演示数据、演示券和配色浮窗不进入正式包。
