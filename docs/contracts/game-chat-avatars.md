# 游戏聊天头像缓存

2026-10-11 用户要求：玩家离线后头像继续保留，服务器持久保存小尺寸头像；Alt+T 只留给表情轮盘，解绑 TAC 配置入口。

`GET /api/v1/chat/avatars/{gameId}` 接受已认证 App/游戏聊天会话，仅开放 GET；按服务端账号及游戏目录解析 UUID，拒绝未知、已注销或停用身份，不接受客户端 URL。响应 `data.png` 为 Base64 编码的 8×8 PNG。

Go 从官方会话服务获取该 UUID 的皮肤元数据，只允许 textures.minecraft.net/texture/ 下的固定哈希资源，升级 HTTPS，禁止重定向、任意主机与超大图片；合成底层脸部与外层。`039_game_chat_avatars.sql` 新增按 UUID 主键的持久缓存，每张最多 4096 字节、正常 24 小时刷新，失败 5 分钟退避且保留上次有效头像。换肤后服务器缓存最多存在一天刷新延迟；当前客户端在线观察到的最新皮肤优先。永久注销清理对应头像。

客户端单线程异步请求、最多 256 个缓存项；同一游戏会话保留已见过的皮肤，离线后优先使用，重新进入游戏从服务器恢复头像。切换会话销毁动态头像纹理，晚到响应按会话代次丢弃。头像失败不刷聊天错误提示。

客户端 `keybindings-v2` 一次迁移将 TAC `key.tacz.open_config.desc` 设为 UNKNOWN，并保留 T 快捷聊天 / Alt+T 轮盘 / Enter 完整界面。之后仍尊重玩家自行修改按键。
