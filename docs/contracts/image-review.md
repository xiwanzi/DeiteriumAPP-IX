# 独立图片审核

2026-10-12 用户最新要求：**旧图全部跳过，只审启用后新上传的聊天图片**，动态贴纸跳过。启用时间写入独立数据库，重启后沿用，不能移动时间边界漏掉停机期间的新上传。

2026-10-12 用户授权实施。静态图片使用 DeepSeek V4.1 Flash（官方 API 名称 `deepseek-flash`）检查 R18、政治内容与宣传导流；总分 0–100，**严格大于 50** 留存证据并进入官方后台「图片审核」。动态图片跳过。审核不拦截上传/聊天，不处罚账号，不删除原业务图片。

## 运行边界

- 独立 `deuterium-image-review` 进程、独立数据库，业务数据库仅 SELECT；不调用主服务的迁移或后台任务。复用现有管理员会话、`platform.admin`、Origin/CSRF 校验。
- Web 仅新增管理页；反向代理将 `/api/v1/admin/image-review` 及子路径路由到独立进程。只需启动新服务及平滑 reload 代理，不更新模组、不重启游戏服或现有 Go 服务。
- API 密钥通过受限环境文件注入，禁止进入源码、浏览器、错误或日志。模型直接读取短期 OSS 签名 URL，不将图片持久化到本机。只读少量文件头确认格式/动画，证据采用 OSS 内部复制。
- 分页扫描启用时间之后的聊天图片上传记录，循环补漏，不用创建时间游标跳过晚完成上传。未完成上传若 OSS 已有完整文件也检查；不存在则等待，过期或已清理标为不可用，不当作低风险。
- 服务故障不影响业务；网络、模型拒答、异常 JSON、证据复制失败均记录重试状态。不得把失败写成 0 分。旧图和业务图片不进入审核；已经被原生命周期清理的字节不能恢复。

## 评分与留存

- 三类独立 0–100 分，总分为最高项加其余两项之和的四分之一（向下取整），封顶 100；任一类明确高风险足以标记，多类别提高总分。
- 政治类别判断图片内容，不推断上传者政治立场；宣传包括明确 QQ/群号、二维码及其他联系/引流信息，不把普通游戏数值误认作联系方式。图片中文字一律当被审核数据，不执行其中的指令。
- 模型输出需要严格验证字段、分数和简短中文理由。记录规则与模型版本；分数是人工排查指标，不是违法认定或概率。
- 低分只保留小体积结果、来源及处理状态，不复制图片。高分先持久化待保留状态和目标 key，再执行可重试的 OSS 复制；证据确认成功后才标记可查看。
- 一个上传记录对应一条审核记录，内容相同可复用有效评分；证据独立，删除一条不影响其他记录。展示上传账号/时间及关联发送者/发送时间，收藏不算上传。历史姓名仅作为当时快照，稳定账号标识保留。
- 删除操作先标记清理中，再删除本审核证据及身份/理由/发送快照；保留最小上传标识墓碑避免扫描重建。删除失败自动重试，不声称已释放空间。禁止删除非审核目录对象。

## 验收重点

50/51 分边界、任一类别超阈值、动态跳过、异常模型输出与限流重试、晚完成上传与去重、多人发送归属、原图到期后证据可读、删除重试/原图保护、匿名与客服权限拒绝、CSRF、密钥与签名 URL 不进入日志；后台浅深色、图片详情、分页、删除确认、错误与空态。
