# 社区 Web 商城

首页推荐通过 `GET /api/v1/store/recommendations` 读取，使用已有商城会话鉴权，响应为与公开商品列表相同的商品视图和分页信封（最多 6 件，无续页）。图片绑定、发布快照和当前玩家的优惠预估复用目录实现。每次请求重新选取，响应为 `private, no-store`。

购买热度按最近 30 天创建、资金状态为 PAID / HELD / SETTLED 的官方订单商品件数统计，排除已取消、已退款及已释放的记录。有限和不限库存商品均可进入统计。在当前已发布、在售且有库存的商品中取前 3 件，与其余商品的随机抽样交错展示；成交数据不足时随机补足，总数不超过 6。同一批商品 ID 唯一。普通目录继续使用原有稳定游标。

一级分类使用 `categoryGroup`，跨店同名大类合并；选中二级分类时附加 `subcategory` 精确名称，须同时指定大类，仅用于公开商品目录。两级筛选都能与 `q` 和 `inStock=true` 组合，翻页沿用相同筛选范围。分类数据来自 `GET /api/v1/store/categories` 的所有分页。

目录支持网格、紧凑列表及直接加购。有货筛选在分页前执行，包含不限库存商品。加购读取购物袋版本后提交绝对数量，结果未知时在当前页面重试相同变更编号。

购物袋角标统计当前账号袋内的商品总件数。导航栏、聊天侧栏和购物袋明细共用服务端购物袋快照，过时的版本不可覆盖新版本。购物袋付款确认后重新读取实际剩余商品。商品小计按当前商品单价和数量以整数分相加，最终实付以服务端结算金额为准。

官方单品和购物袋在进入付款确认时自动计算最终金额、可用优惠及店铺拆单，只有玩家明确确认后才提交带稳定请求编号的订单。失效的金额需更新再确认；付款结果未知时先恢复原请求。玩家市场继续收集履约方式、地点及必要的工程名称。此改动无需数据库迁移。
