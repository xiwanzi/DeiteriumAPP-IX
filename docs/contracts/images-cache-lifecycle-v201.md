# 2.0.1 图片读取与生命周期增量契约

2026-09-08。配合 App 2.0.1 (20100)，覆盖 [雨云 S3 直传契约](assets-rainyun-s3-v2.md) 中有关长期素材保留和图片读取的说明。身份、资金、上传 MD5/SHA-256 校验与业务授权边界不变。

## 图片身份与响应

assetId 对应不可变图片字节。更换头像或重新上传生成新 assetId；历史订单与仍在售商品继续复用原 assetId，不为每笔订单复制素材。前缀迁移只改变服务端 object_key，不改变 assetId、内容 SHA-256 或订单快照。

业务返回的 Asset 增加以下字段：

| 字段 | 含义 |
| --- | --- |
| status | READY 或 EXPIRED；EXPIRED 返回空 url，但保留资产身份、摘要和尺寸 |
| contentType | 已验证的 MIME 类型 |
| retentionStatus | ACTIVE / MOVING / RETIRED / RESTORING / EXPIRED / PURGED，供状态核对 |
| retainUntil | 可空 UTC 时间。只有退入回收前缀后才开始 30 天保留期；恢复有效用途后清空 |
| urlExpiresAt | 下载签名的短期限，与 retainUntil 分开处理 |

客户端可以缓存已授权的普通图片字节。assetId 加服务与账号范围构成缓存身份，SHA-256 校验完整性；短期签名 URL 变化不表示图片内容变化。缓存未命中且链接失效，重新 GET 原授权业务资源；不能绕过业务可见性，把他人的 assetId 传给仅限所有者的 /assets/{assetId}。

订单读取增加 images 数组，内容由 ORDER_SNAPSHOT 的已授权绑定生成，不改动 items、snapshotSha256 或冻结快照。案件读取增加 snapshotAssets，将当前图片可用性与不可变证据快照分开。EXPIRED 图片不使订单或案件详情整体失败。

## 回收与恢复

仅当所有引用都已成为历史用途或没有引用时进入回收。当前头像、有效店铺/公告引用、在售商品、草稿、进行中的委托/订单、资金未知、退款处理中、未结束介入阻止回收。下架/归档商品与已完成交易仍可保存图片引用，但不再无限期阻止清理。

测试环境专用前缀为 deuterium-test/gc/，生命周期规则为存在满 30 天异步删除；不能把到期删除规则应用到整个 deuterium-test/ 或 uploads/。新对象年龄从校验成功的回收副本 LastModified 开始，原 key 在数据库切换完成后删除。预先校验所有上传授权已过期，防止旧 PUT 重建原对象。

ACTIVE → MOVING → RETIRED → EXPIRED → PURGED。复制、数据库切换、原对象删除分别可恢复，重试复用目标 key，不重复重置保留期。PURGED 表示已核对对象缺失，不能仅由时间推断物理删除完成。

再次上架或恢复有效用途时，RETIRED 且未过期的图片先经 RESTORING 复制并校验回有效前缀，再允许业务绑定；已经过期则需要重新选图。开启已结算订单的介入会重新保护仍可用的原图片，已过期图片不会阻止基于现有文字和交易记录开案。

新绑定与回收共享资产行锁。网络 IO 在短事务之外进行，后台执行与显式恢复串行。ASSET_BUSY 为 503、可重试；原资源的鉴权、幂等和交易失败优先级继续生效。

## 本机存储管理

内存缓存上限为应用最大堆的 10% 且不超过 32 MiB；磁盘总预算最多 200 MiB，按剩余空间缩减。图片下载并发最多 3，同图合并。清理以真实缓存文件为依据，旧请求不能在清理后写回。

“我的 → 存储空间”统计图片缓存、更新下载、临时文件及应用/业务数据，支持分类或全部清理。账号、聊天、订单与正在使用的资源保持。正在下载、验证或安装的更新文件不可清理。新选图暂存文件用后释放；旧版本仅清理超过 24 小时且未被头像偏好引用的已知暂存文件名，其他用户文件不被归为缓存。

争议凭证默认不持久缓存，也不使用跨页面内存复用。缓存清理不是退出账号或删除云端资源。
