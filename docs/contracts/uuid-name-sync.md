# 同 UUID 正版改名同步

2026-10-13 用户授权实施。正版 UUID、平台 userId/playerRef、Cloud account/identity、公会成员身份和资产归属保持；自动更新正版游戏 ID、登录别名及各端玩家名称展示。中文昵称和佩戴头衔保持。真实正版改名暂无法验收，本轮使用隔离身份供应商、同 UUID 新旧名字、跨服/重启/并发的代码测试，不将模拟证据写成真实改名验证。

## 身份与触发

- 游戏在线身份变化经已认证 Core 通路发现，由正版资料核验后更新；不能接受客户端自行提交 UUID/name 来迁移身份。离线旧缓存不是新名字权威。
- 新游戏名登录通过正版资料查到原 UUID，仍校验原平台密码；验证成功后同步名称并签发原账号会话。邮箱/QQ 登录能力保留。
- 2026-10-25 候选：已知名字和正确密码先按本地平台别名登录，后台按稳定 UUID 更新名字；新名字和本地验证不匹配才等待官方。会话提交前在事务内复核别名归属，后台更新不迁移已签发会话或资产。允许尚未观测到改名时的别名滞后，详见[快速登录边界](../plans/login-fast.md)。
- 名称更新采用有版本、可重试的事务，名称冲突不能偷取其他账号的登录别名；禁止恢复已注销账号、自动新增重复账号或改变 UUID。
- 纯自动名称刷新不撤销原有效会话，不修改密码、邮箱、QQ、昵称、权限、头衔及金额。已人工修改账号身份的管理流程仍保留其独立安全规则。

## 展示和同步

- 发布按稳定玩家标识关联的名称变更；App、Web、游戏聊天更新已加载联系人、会话、消息头、个人资料和必要持久缓存。聊天正文不做字符串替换。
- 订单、账单、委托、通知中的结构化玩家引用在读出时投影最新游戏 ID；不可变交易快照、金额、消息原文、签名摘要及历史事实不重写。
- 公会/领地使用 UUID 成员关系和名字映射，登录更新共享名字；离线节点重启的旧本地缓存不得覆盖已更新名字。
- Cloud 正版身份按 UUID 复用，认证使用最新正版名字；持有同 UUID 的旧 Cloud 绑定、模型和权限保留。验证过程中改名可重新获取一次认证挑战，不绕过正版证明或重放保护。
- 盘点现有 Core、Gateway、铭牌/TAB、经济、邮件、同步、任务及启动器的 UUID/名称用途。能由正常正版重登录自行更新的原生/第三方显示记录其机制；发现自有名称缓存或按名授权则修复，不能用“UUID 不变”替代具体检查。

## 验证

同 UUID 改名保留账号/资产/昵称/头衔；旧名释放及被他人使用不串号；新名登录、错误密码不更新身份；同次刷新幂等、并发与跨服旧缓存；页面与缓存刷新；不可变订单快照不变；Cloud 新名证明继续归属原账号；公会关系/领地不变，旧离线快照不回写新名。
