## 本轮改动

启动版本徽标采用透明普通 drawable，取消系统 adaptive-icon 方形轮廓；保留四入口、现有材质、布局和动效。注册与关于页继续使用 App 图标。

移除固定验证码、任意登录、示例商品/联系人/委托/公告/消息/余额与模拟订单、管理员工具。升级保留外观设置，旧体验会话和本机钱包快照不迁入真实账号。App 标题为 Deuterium，版本文案为 2.0.0。

默认后端为 `https://47.103.99.34`，由 `-PdeuteriumApiBase=https://...` 配置构建目标。使用系统 TLS 校验；服务器、数据库、S3 与游戏服密钥不进入 App。

## 数据与业务边界

- 真实登录、游戏验证码注册/改密、会话查询与撤销；令牌由 Android Keystore AES-GCM 加密保存并绑定后端 origin。早期候选未记录 origin 的会话在升级后需重新认证一次。
- 公共 WebSocket 历史、收发、引用、提及、ACK、重连去重；私聊与转发按服务端会话隔离，结果未知保留原消息 ID。通知与偏好由服务器读取，当前后台提醒依赖 App 进程存活。
- 官方商品/市场目录、上架与下架、购物袋及服务器报价；商品介绍和图片来自接口。资产经短期授权直传雨云 S3，完成核验达到 READY 后才绑定 assetId。
- 钱包、订单、退款、委托和平台介入均使用权威接口；客户端不改余额、不自行冻结、退款或到期结算。付款只有服务端确认完成后显示成功，处理中或未知结果保留请求并继续核对。
- 转账和购买/委托预付待处理请求按原账号与 origin 保存。购买/预付仅在没有 operationId 且原 clientRequestId 被服务器明确判定 NOT_FOUND 时重放原 ID、原 body；已登记操作只查询。原报价过期要求重新确认，不自动换报价/金额/幂等键。旧记录缺少身份或 origin 时保留核对，禁止自动付款。
- 应用/资源更新读取真实清单，移除随包演示更新；保留进度、完整性、签名和版本校验。

服务端能力未就绪时显示返回错误或空态，不回退本机成功。AI 已接通服务端 DeepSeek V4 Flash 流式回复与按需联网搜索，原请求 ID 可恢复；前端展示实际来源并忽略内部推理。免费额度每 24 小时 20 次，平台管理员免计数；付费套餐仅展示不可购买状态。支付视觉不采集人脸，不构成真实生物识别服务。

## 构建与验证

使用项目 Gradle wrapper：

```powershell
./gradlew.bat :ui-lab:assembleDebug :ui-lab:testDebugUnitTest :ui-lab:lintDebug --console=plain
```

独立 QA 仪器仅用于受控联调，可用 `:ui-lab:assembleDebugAndroidTest` 构建；不会打入交付 APK。它读取短期 QA 会话后立即删除原文件，不记录令牌，不修改玩家密码。
