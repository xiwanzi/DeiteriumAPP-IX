# 网页 2.0.0 连接版增量验收

日期：2026-09-08。面向 Deuterium IX。此报告对应去掉演示入口后新增的实际社交、资料、管理、市场、图片、AI、模板、资金与平台处理界面；不替换较早同日的钱包正式化记录。

## 已完成改动

只有服务器登录。公共/私聊收发、引用、转发、资料和关注；头像 S3 PUT 后绑定；公告草稿/预览/发布/撤下与图片；通知已读/偏好；市场发布/编辑/上下架；商店/品牌/分类/商品草稿管理；按 Core 批准版本创建、编辑、停用交付模板。

网页注册使用 `/web/register` 的 HttpOnly Cookie，不使用 App 注册端点索取 Bearer。每个会话的 CSRF 只在内存；AI 与聊天请求编号按账号保存以便断流后恢复。

AI 接入服务端 SSE：正文、状态、来源、完成/错误、历史、`/new`。免费 20 次/24 小时；管理员不限制次数；其他计划 9999999.00 且不可购买。来源仅 HTTP(S)，`provider_text` 标为“正文链接”，只有 `searchUsed=true` 才显示使用了联网搜索。客户端不含 API Key，也不展示思考内容。
