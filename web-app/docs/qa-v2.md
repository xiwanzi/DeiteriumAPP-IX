## 真实链路的含义

实际运行未经修改的 Go Foundation `8db1109` Windows 构建，使用**本次新建的隔离 MariaDB 数据目录**、回环 33719 端口及 `deuterium_web_v2_20260908` 数据库。后端监听 127.0.0.1:28671，网页网关监听 127.0.0.1:5182。

账号为合成的 WebMori；Core 为回环模拟客户端 webtest。执行了实际数据库迁移、合成旧哈希导入、登录后的 Cookie、真实 WS/HTTP、Core 入库和消息 ACK。未连接真实游戏服、未迁移生产账号、未接触 XConomy 或邮箱数据库，未部署 Linux/公网。

已确认：Cookie 为 HttpOnly/SameSite=Lax，JavaScript 不可读会话；真实密码/CSRF 不在 LocalStorage；错误 CSRF 与登录 Origin 被后端拒绝；退出使现有额外 WS 连接被服务端关闭；刷新后从 SQL 读回消息；Core 离线不会假报发送成功；恢复后保留原消息 ID 并去重。

这里是 HTTP/WS 回环开发模式，不声称已验收生产 Secure Cookie、HTTPS/WSS 或远程代理部署。

## UI 与业务检查

- 玩家汇总包含所有合成账号。净出售额准确扣除部分/全额退款；未付款取消不计入；委托、转账不污染商品销售额。
- 点击玩家进入其参与的逐笔交易，角色/渠道过滤不扩大账号范围；交易详情显示退款、结算、担保和成交摘要；CSV 与筛选结果一致并防护公式注入。
- 公告新建仅为草稿。预览返回编辑不会提交；显式发布才出现在玩家页。公开后的编辑保留原发布版本，撤下后不再公开。
- PC 聊天占满可用窗口，桌面应用侧栏收窄，移动端列表/会话切换；会话草稿、消息搜索与普通发送可用。
- 实际连接模式中的钱包等未实现能力显示不可用，未回退到演示余额或订单。
- 目视检查登录、手机登录、玩家销售、公告管理、深色聊天、手机消息等代表截图，修正过表单按钮误提交、忘记密码换行与实景黑边。
