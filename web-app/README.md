# Deuterium Web 2.0.0

2026-09-08。面向 Deuterium IX 的玩家网站与官方管理入口。本版仅使用服务器账号和业务接口，已移除演示登录、预览入口、合成余额、示例公告和委托。旧 /preview 地址转到对应真实页面，旧演示存储会被清除。版本号与 App 对齐为 2.0.0。

## 本版能力

- Deuterium ID 登录、会话恢复和退出；Cookie 为 HttpOnly，CSRF 只在内存中。注册与找回表单使用游戏内验证码接口，服务没有开放时显示真实错误。
- 公共聊天 HTTP 历史、WebSocket 收发、重连、引用与提及；真实私聊、引用、人工转发、联系人、特别关心，按账号和会话隔离。断线使用原消息编号恢复。
- 服务器余额和账单、刷新余额、权威收款玩家查询、二次确认转账。金额使用十进制字符串，失败不显示为 0；未知结果保留同一请求，可刷新页面后继续核对，不自行扣款。
- 真实玩家市场发布、编辑、下架与重新上架，图片直传；商店创建/资料、品牌/分类、商品草稿/发布/下架、Core 邮箱交付模板管理。购物袋、最终报价、二次确认购买、订单/委托列表、成交约定、发货/施工/完成/验收、退款申请/撤回/处理均使用 013 接口。
- 个人简介与头像、公告草稿/编辑/预览/发布/撤下、通知已读及十项通知偏好，均通过实际 API 持久化。保存公告草稿不会提前公开，媒体按资源绑定签发下载地址。
- AI 使用服务端 DeepSeek V4 Flash 与可选联网搜索，SSE 正文/来源、历史、/new、同 ID 断流恢复。免费 20 次/24 小时、平台管理员不限；其他计划显示 9999999.00 且关闭购买。网页不含供应商 Key，正文 URL 标为正文链接，不伪称已核验。
- 管理入口依据服务返回的 permissions 显示，所有后台 API 继续服务端鉴权。物品交付模板只选择 Core 批准的版本、数量、摘要及兼容领取服务器，不接受原始物品字节或任意命令。
- 平台介入支持申请、补充证据、撤回、管理员受理/要求资料/裁决。聊天资料由本人选择，仅提交可访问的消息引用，处理页显示服务端快照。管理审计使用只读接口，支持权限、精确筛选、最多 90 天范围与冻结游标。
- 付款与委托预付在提交前保存原请求；响应丢失后查询原 operation，刷新不会创建第二次付款。详情按服务端 pendingOperationId 与 availableActions 展示恢复状态，不在本地模拟冻结/结算/退款。
- 保留原有品牌素材、桌面聊天布局、浅深色和移动端适配。产品页面不显示后端工程名称与演示文案。

## 运行与构建

需要 Node.js 22.12+ 或 24。

```powershell
npm ci
npm test
npm run build
$env:WEB_API_ORIGIN = 'http://127.0.0.1:8080'
$env:WEB_PORT = '5180'
npm start
```

开发可运行 npm run dev；修改 WEB_API_ORIGIN 后重启。Node 网关仅接受固定后端 Origin，保留浏览器 Cookie/Origin；未配置目标时返回 503，不切换演示身份。

## 静态部署

当前测试入口采用 [服务器 IP](https://47.103.99.34)，域名备案期间不用域名。

只上传 dist 即可，无需 Node 常驻：Nginx 静态服务使用 SPA 回退；同域 /api/v1 直接代理到 127.0.0.1:8080，包含 /api/v1/chat/ws 的 WebSocket Upgrade。后端 publicOrigin 必须是 https://47.103.99.34。API 直接经过受信 Nginx，避免 Node 网关将真实地址覆盖为回环。

详见 [部署说明](docs/deployment-v2.md)。实际远程上传、TLS 和游戏服联通由本轮主任务统一记录，本文不把本机构建写成已上线。
